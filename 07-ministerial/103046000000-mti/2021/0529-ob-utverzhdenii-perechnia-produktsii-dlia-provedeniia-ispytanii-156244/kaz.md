# Техникалық регламенттер талаптарына сәйкестігіне сынақтар жүргізу үшін өнімдер тізбесін бекіту туралы

> *Ескерту. 01.07.2021 бастап қолданысқа енгізіледі – осы бұйрықтың 4-тармағымен.*

«Техникалық реттеу туралы» Қазақстан Республикасы Заңының 43-бабының 1-тармағына сәйкес БҰЙЫРАМЫН:

<a id="p1"></a>

1. Қоса беріліп отырған Техникалық регламенттер талаптарына сәйкестігіне сынақтар жүргізу үшін өнімдер тізбесі бекітілсін.

<a id="p2"></a>

2. Қазақстан Республикасы Сауда және интеграция министрлігінің Техникалық реттеу және метрология комитеті заңнамада белгіленген тәртіппен:

   1) осы бұйрықты Қазақстан Республикасы Әділет министрлігінде мемлекеттік тіркеуді;

   2) осы бұйрықты Қазақстан Республикасы Сауда және интеграция министрлігінің интернет-ресурсында орналастыруды қамтамасыз етсін.

<a id="p3"></a>

3. Осы бұйрықтың орындалуын бақылау жетекшілік ететін Қазақстан Республикасының Сауда және интеграция вице-министріне жүктелсін.

<a id="p4"></a>

4. Осы бұйрық 2021 жылғы 1 шілдеден бастап қолданысқа енгізіледі және ресми жариялануға тиіс.

**Қазақстан Республикасының сауда және интеграция министрі**

**Б. Сұлтанов**

> *«КЕЛІСІЛДІ»*  
> *Қазақстан Республикасы*  
> *Ұлттық экономика министрлігі*

> *Қазақстан Республикасының*  
> *сауда және интеграция министрінің*  
> *2021 жылғы 29 мамырдағы № 374-НҚ*  
> *Бұйрығымен бекітілген*

## Техникалық регламенттер талаптарына сәйкестігіне сынақтар жүргізу үшін өнімдер тізбесі

<a id="an1_p1"></a>

1. Төмен вольтты жабдық.

<a id="an1_p2"></a>

2. Электромагниттік кедергілер жасауға қабілетті және (немесе) жұмыс істеу сапасы сыртқы электромагниттік кедергілердің әсеріне байланысты болатын техникалық құралдар.

<a id="an1_p3"></a>

3. Қауіпті заттары бар электр техникасы мен радиоэлектроника бұйымдары.

<a id="an1_p4"></a>

4. Машиналар мен жабдық.

<a id="an1_p5"></a>

5. Лифтілер.

<a id="an1_p6"></a>

6. Автокөлік және авиациялық бензин, дизель және кеме отыны, реактивті қозғалтқыштарға арналған отын және мазут.

<a id="an1_p7"></a>

7. Газ тәрізді отынмен жұмыс істейтін аппараттар.

<a id="an1_p8"></a>

8. Доңғалақты көлік құралдары және олардың компоненттері.

<a id="an1_p9"></a>

9. Майлау материалдары, майлар және арнайы сұйықтықтар.

<a id="an1_p10"></a>

10. Ауыл шаруашылығы, орман шаруашылығы тракторлары және олардың тіркемелері, және олардың компоненттері.

<a id="an1_p11"></a>

11. Отын ретінде пайдалану үшін сұйытылған көмірсутекті газ.

<a id="an1_p12"></a>

12. Аттракциондар.

<a id="an1_p13"></a>

13. Балалар ойын алаңдарына арналған жабдық.

<a id="an1_p14"></a>

14. Өрт қауіпсіздігін қамтамасыз ету және өрт сөндіру құралдары.

<a id="an1_p15"></a>

15. Көмір және оны қайта өңдеу өнімдері.

<a id="an1_p16"></a>

16. Қаптама.

<a id="an1_p17"></a>

17. Құрылыс материалдары мен бұйымдары.

<a id="an1_p18"></a>

18. Жедел-іздестіру іс-шараларын өткізуді, абоненттер туралы қызметтік ақпаратты жинау және сақтауды қамтамасыз ету бойынша телекоммуникациялық жабдық.

<a id="an1_p19"></a>

19. Артық қысыммен жұмыс істейтін жабдық.

<a id="an1_p20"></a>

20. Жеңіл өнеркәсіп өнімдері.

<a id="an1_p21"></a>

21. Жеке қорғану құралдары.

<a id="an1_p22"></a>

22. Жиһаз өнімдері.

<a id="an1_p23"></a>

23. Синтетикалық жуғыш заттар және тұрмыстық химия тауарлары.

<a id="an1_p24"></a>

24. Лак-бояу материалдары мен еріткіштер.

<a id="an1_p25"></a>

25. Пиротехникалық бұйымдар.

<a id="an1_p26"></a>

26. Балалар мен жасөспірімдерге арналған өнімдер.

<a id="an1_p27"></a>

27. Ойыншықтар.

<a id="an1_p28"></a>

28. Жарылу қаупі бар орталарда жұмыс істеуге арналған жабдық.

<a id="an1_p29"></a>

29. Шағын көлемді кемелер.

<a id="an1_p30"></a>

30. Жарылғыш заттар және олардың негізіндегі бұйымдар.

<a id="an1_p31"></a>

31. Теміржол жылжымалы құрамы.

<a id="an1_p32"></a>

32. Жоғары жылдамдықты теміржол көлігі.

<a id="an1_p33"></a>

33. Теміржол көлігінің инфрақұрылымы.

<a id="an1_p34"></a>

34. Автомобиль жолдарының қауіпсіздігін қамтамасыз ететін жол-құрылыс материалдары мен бұйымдары.

<a id="an1_p35"></a>

35. Тасымалдауға және (немесе) пайдалануға дайындалған табиғи жанғыш газ.

<a id="an1_p36"></a>

36. Тасымалдауға және (немесе) пайдалануға дайындалған мұнай.

<a id="an1_p37"></a>

37. Энергияны тиімді тұтынатын құрылғылар.
