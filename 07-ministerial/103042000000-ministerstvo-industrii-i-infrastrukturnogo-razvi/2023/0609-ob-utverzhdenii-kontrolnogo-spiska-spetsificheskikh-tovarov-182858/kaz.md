# Өзіндік ерекшелігі бар тауарлардың бақылау тізімін бекіту туралы

«Өзіндік ерекшелігі бар тауарларды бақылау туралы» Қазақстан Республикасы Заңының 8-бабының 5) тармақшасына сәйкес БҰЙЫРАМЫН:

<a id="p1"></a>

1. Қоса беріліп отырған Өзіндік ерекшелігі бар тауарлардың бақылау тізімі бекітілсін.

<a id="p2"></a>

2. Қазақстан Республикасы Индустрия және инфрақұрылымдық даму министрлігінің Индустриялық даму комитеті заңнамада белгіленген тәртіппен:

   1) осы бұйрықты Қазақстан Республикасы Әділет министрлігінде мемлекеттік тіркеуді;

   2) осы бұйрықты Қазақстан Республикасы Индустрия және инфрақұрылымдық даму министрлігінің интернет-ресурсында орналастыруды қамтамасыз етсін.

<a id="p3"></a>

3. Осы бұйрықтың орындалуын бақылау жетекшілік ететін Қазақстан Республикасының Индустрия және инфрақұрылымдық даму вице-министріне жүктелсін.

<a id="p4"></a>

4. Осы бұйрық алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`ch001`](kaz/ch001.md) | `!` Өзіндік ерекшелігі бар тауарлардың бақылау тізімі |
| [`ch001-t001`](kaz/ch001-t001.md) | таблица 1 |
| [`ch001-part002`](kaz/ch001-part002.md) | ch001-part002 |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
