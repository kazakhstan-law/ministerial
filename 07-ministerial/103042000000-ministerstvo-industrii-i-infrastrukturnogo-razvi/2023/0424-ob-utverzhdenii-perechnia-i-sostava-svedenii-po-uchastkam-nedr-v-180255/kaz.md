# Ашық қолжетімділікте жариялануға жататын, мемлекеттік жер қойнауы қорын басқару бағдарламасына енгізілген жер қойнауы учаскелері жөніндегі мәліметтердің тізбесі мен құрамын бекіту туралы

«Жер қойнауы және жер қойнауын пайдалану туралы» Қазақстан Республикасы Кодексінің 70-бабының 6-тармағына сәйкес БҰЙЫРАМЫН:

<a id="p1"></a>

1. Осы бұйрыққа қосымшаға сәйкес ашық қолжетімділікте жариялануға жататын, мемлекеттік жер қойнауы қорын басқару бағдарламасына енгізілген жер қойнауы учаскелері жөніндегі мәліметтердің тізбесі мен құрамы бекітілсін.

<a id="p2"></a>

2. Қазақстан Республикасы Индустрия және инфрақұрылымдық даму министрлігінің Геология комитеті заңнамада белгіленген тәртіпте:

   1) осы бұйрықтың Қазақстан Республикасы Әділет министрлігінде мемлекеттік тіркелуін;

   2) осы бұйрықты Қазақстан Республикасы Индустрия және инфрақұрылымдық даму министрлігінің интернет-ресурсында орналастырылуын қамтамасыз етсін.

<a id="p3"></a>

3. Осы бұйрықтың орындалуын бақылау жетекшілік ететін Қазақстан Республикасының Индустрия және инфрақұрылымдық даму вице-министріне жүктелсін.

<a id="p4"></a>

4. Осы бұйрық алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Қазақстан Республикасы Индустрия және инфрақұрылымдық даму министрінің міндетін атқарушы**

Кестені толтыру мысалы:

<a id="an0_p1"></a>

1. р/с - реттік саны;

<a id="an0_p2"></a>

2. Аумақтың, учаскенің, кен орнының атауы - мемлекеттік жер қойнауы қорын басқару бағдарламасына енгізілген аумақтың, учаскенің, кен орнының атауы;

<a id="an0_p3"></a>

3. Аймақтың атауы – облыстың атауы;

<a id="an0_p4"></a>

4. Тиісті координаттары мен жеке кодтары бар блоктарды сәйкестендіру картасы (секция, кіші бөлім, блок) (мысалы: M-39-66-(10а-5а-1));

<a id="an0_p5"></a>

5. Ауданы (шаршы километр) – тек шаршы километрде көрсетіледі;

<a id="an0_p6"></a>

6. Пайдалы қазба түрі, жер қойнауын пайдалану жөніндегі операциялардың түрі - қатты пайдалы қазбалар, кең таралған пайдалы қазбалар, көмірсутектер; жер қойнауын геологиялық зерттеу, пайдалы қазбаларды барлау, пайдалы қазбаларды өндіру;

<a id="an0_p7"></a>

7. Сұрау салынған аумақтың кеңістіктік шекаралары (географиялық координаттары) – (Солтүстік ендік-градус / минут / секунд / шығыс бойлық-градус / минут / секунд) (мысалы: 46° 33' 00" - 53° 06' 00");

<a id="an0_p8"></a>

8. Аумақтың зерттелуі (парақ номенклатурасы) және қолда бар қорлары (мысалы: L-39-XXIV).
