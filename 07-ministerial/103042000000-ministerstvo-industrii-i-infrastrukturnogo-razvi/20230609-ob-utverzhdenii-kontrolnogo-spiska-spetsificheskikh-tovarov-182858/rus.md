# Об утверждении Контрольного списка специфических товаров

В соответствии с подпунктом 5) статьи 8 Закона Республики Казахстан «О контроле специфических товаров» ПРИКАЗЫВАЮ:

1. Утвердить прилагаемый Контрольный список специфических товаров.

2. Комитету индустриального развития Министерства индустрии и инфраструктурного развития Республики Казахстан в установленном законодательством порядке обеспечить:

   1) государственную регистрацию настоящего приказа в Министерстве юстиции Республики Казахстан;

   2) размещение настоящего приказа на интернет-ресурсе Министерства индустрии и инфраструктурного развития Республики Казахстан.

3. Контроль за исполнением настоящего приказа возложить на курирующего вице-министра индустрии и инфраструктурного развития Республики Казахстан.

4. Настоящий приказ вводится в действие по истечении десяти календарных дней после его первого официального опубликования.

## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`ch001`](rus/ch001.md) | `!` Контрольный список специфических товаров |
| [`ch001-t001`](rus/ch001-t001.md) | таблица 1 |
| [`ch001-part002`](rus/ch001-part002.md) | `!` ch001-part002 |
| [`ch001-t002-r001`](rus/ch001-t002-r001.md) | таблица 2, строки 1–251 |
| [`ch001-t002-r002`](rus/ch001-t002-r002.md) | таблица 2, строки 252–488 |
| [`ch001-t002-r003`](rus/ch001-t002-r003.md) | таблица 2, строки 489–517 |
| [`ch001-part006`](rus/ch001-part006.md) | `!` ch001-part006 |
| [`ch001-t003`](rus/ch001-t003.md) | таблица 3 |
| [`ch001-part008`](rus/ch001-part008.md) | ch001-part008 |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
