## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`intro`](kaz/intro.md) | Тарих және мәдениет ескерткіштеріндегі ғылыми-реставрациялық жұмыстардың орындалуын бағалау нормативтерін бекіту туралы |
| [`intro-t001-r002`](kaz/intro-t001-r002.md) | таблица 1, строки 1818–3710 |
| [`intro-t001-r003`](kaz/intro-t001-r003.md) | таблица 1, строки 3711–5356 |
| [`intro-t001-r004`](kaz/intro-t001-r004.md) | таблица 1, строки 5357–7201 |
| [`intro-t001-r005`](kaz/intro-t001-r005.md) | таблица 1, строки 7202–9000 |
| [`intro-t001-r006`](kaz/intro-t001-r006.md) | таблица 1, строки 9001–10158 |
| [`intro-part007`](kaz/intro-part007.md) | intro-part007 |
| [`part001`](kaz/part001.md) | `!` Қазақстан Республикасының тарих және мәдениет ескерткіштеріндегі ғылыми-зерттеу жұмыстарының барлық түрлері үшін қолайсыз кезеңнің ұзақтығы |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
