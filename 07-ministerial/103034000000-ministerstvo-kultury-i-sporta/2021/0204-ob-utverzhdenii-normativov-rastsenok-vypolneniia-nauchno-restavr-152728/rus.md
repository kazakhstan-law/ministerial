## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`intro`](rus/intro.md) | Об утверждении Нормативов расценок выполнения научно-реставрационных работ на памятниках истории и культуры |
| [`intro-t001-r002`](rus/intro-t001-r002.md) | таблица 1, строки 1569–3213 |
| [`intro-t001-r003`](rus/intro-t001-r003.md) | таблица 1, строки 3214–4726 |
| [`intro-t001-r004`](rus/intro-t001-r004.md) | таблица 1, строки 4727–6246 |
| [`intro-t001-r005`](rus/intro-t001-r005.md) | таблица 1, строки 6247–7857 |
| [`intro-t001-r006`](rus/intro-t001-r006.md) | таблица 1, строки 7858–9419 |
| [`intro-t001-r007`](rus/intro-t001-r007.md) | таблица 1, строки 9420–10407 |
| [`intro-part008`](rus/intro-part008.md) | intro-part008 |
| [`part001`](rus/part001.md) | `!` Продолжительность неблагоприятного периода, для всех видов научно-исследовательских работ на памятниках истории и культуры Республики Казахстан |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
