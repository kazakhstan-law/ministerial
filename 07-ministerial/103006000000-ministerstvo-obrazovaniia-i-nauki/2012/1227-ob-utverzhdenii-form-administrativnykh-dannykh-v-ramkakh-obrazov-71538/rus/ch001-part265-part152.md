## Толтыру бойынша нұсқау / Инструкция по заполнению

Бакалавриат бағдарлама бойынша білім алушылардың жылдық орташа контингентті, адам-бұл бакалавриат бағдарлама бойынша білім алушылардың саны болып табылатын оқу мекемесінің сметалық шығындары көлемін анықтайтын негізгі көрсеткіштердің бәрі/Среднегодовой контингент обучающихся по программам бакалавриата, чел - это один из основных показателей, определяющих объем расходов по сметеучебного заведения, является численность обучающихся по программам бакалавриата.

Магистратура бағдарлама бойынша білім алушылардың жылдық орташа контингентті, адам-бұл магистратура бағдарлама бойынша білім алушылардың саны болып табылатын оқу мекемесінің сметалық шығындары көлемін анықтайтын негізгі көрсеткіштердің бәрі /Среднегодовой контингент обучающихся по программам магистратуры, чел - это один из основных показателей, определяющих объем расходов по смете учебного заведения, является численность обучающихсяя по программам магистратуры.

Докторантура бағдарлама бойынша білім алушылардың жылдық орташа контингентті, адам-бұл докторантура бағдарлама бойынша білім алушылардың саны болып табылатын оқу мекемесінің сметалық шығындары көлемін анықтайтын негізгі көрсеткіштердің бәрі /Среднегодовой контингент обучающихся по программам докторантуры, чел -это один из основных показателей, определяющих объем расходов по смете учебного заведения, является численность обучающихся по программам докторантуры
