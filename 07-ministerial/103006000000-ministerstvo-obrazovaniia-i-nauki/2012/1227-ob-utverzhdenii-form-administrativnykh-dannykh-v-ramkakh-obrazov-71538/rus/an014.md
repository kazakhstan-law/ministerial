## Пояснение по заполнению формы, предназначенной для сбора административных данных

## «Сведения о сети организаций дополнительного образования. Сведения о контингенте организаций дополнительного образования. Контингент учащихся по возрастным категориям и социальному статусу» (Индекс: № ВУ-1, периодичность – годовая)

<a id="an17_p1"></a>

1. Арифметико-логический контроль:

   раздел 1

   графа 32=∑ граф 1-31 для каждой строки

   строка 1=∑ строк 1.1, 1.2 для каждой графы

   раздел 2

   строка 1=∑ строк 1.1, 1.2 для каждой графы.

   раздел 3

   графа 32=∑ граф 1-31 для каждой строки

   строка 1=∑ строк 1.1, 1.2 для каждой графы.

   строка 1.1=∑ строк 1.1.1-1.1.3 для каждой графы.

   строка 1.2=∑ строк 1.2.1-1.2.3 для каждой графы.

   форма ВУ-1 раздел 2 строка 1 графа 32 = форма ВУ-1 раздел 3 строка 1 графа 32 = форма ВУ-2 раздел 2 строка 1 = ∑ граф 1-19 для каждой строки
