## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`intro`](rus/intro.md) | Об утверждении перечня учебников и базовых учебников по отдельным предметам для организаций среднего образования, учебно-методических комплексов для дошкольных организаций, организаций среднего образования, в том числе в электронной форме |
| [`intro-t001-r001`](rus/intro-t001-r001.md) | `!` таблица 1, строки 5–640 |
| [`intro-t001-r002`](rus/intro-t001-r002.md) | `!` таблица 1, строки 641–1280 |
| [`intro-t001-r003`](rus/intro-t001-r003.md) | `!` таблица 1, строки 1281–1780 |
| [`intro-t001-r004`](rus/intro-t001-r004.md) | `!` таблица 1, строки 1781–2265 |
| [`intro-t001-r005`](rus/intro-t001-r005.md) | `!` таблица 1, строки 2266–2845 |
| [`intro-t001-r006`](rus/intro-t001-r006.md) | `!` таблица 1, строки 2846–3510 |
| [`intro-t001-r007`](rus/intro-t001-r007.md) | `!` таблица 1, строки 3511–4112 |
| [`intro-t001-r008`](rus/intro-t001-r008.md) | `!` таблица 1, строки 4113–4583 |
| [`intro-t001-r009`](rus/intro-t001-r009.md) | таблица 1, строки 4584–4662 |
| [`h003`](rus/h003.md) | Английский язык |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
