## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`intro`](rus/intro.md) | Об утверждении перечня учебников и базовых учебников по отдельным предметам для организаций среднего образования, учебно-методических комплексов для дошкольных организаций, организаций среднего образования, в том числе в электронной форме |
| [`intro-t001-r001`](rus/intro-t001-r001.md) | `!` таблица 1, строки 5–2272 |
| [`intro-t001-r002`](rus/intro-t001-r002.md) | `!` таблица 1, строки 2273–4594 |
| [`intro-t001-r003`](rus/intro-t001-r003.md) | таблица 1, строки 4595–4662 |
| [`h003`](rus/h003.md) | Английский язык |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
