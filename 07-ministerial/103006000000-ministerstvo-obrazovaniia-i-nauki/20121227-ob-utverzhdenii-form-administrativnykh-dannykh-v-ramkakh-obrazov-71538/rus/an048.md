   В графах 1-12 указывается количество учащихся по классам.

   В графах 14-16 указывается количество педагогических кадров по образованию.

   В графах 17-24 указывается количество педагогических кадров по категориям.

2. Арифметико-логический контроль:

   графа 13 = ∑ граф 14-16 для каждой строки = ∑ граф 17-24 для каждой строки

   строка 1.2 = ∑ строк 1-1.1 для каждой графы

   строка 2.2 = ∑ строк 2-2.1 для каждой графы

   строка 3.2 = ∑ строк 3-3.1 для каждой графы

3. Контроль между формами:

      форма П-7 строка 1.2 ∑ граф 1-12 = форма П-3 (2 раздел) графа 14
