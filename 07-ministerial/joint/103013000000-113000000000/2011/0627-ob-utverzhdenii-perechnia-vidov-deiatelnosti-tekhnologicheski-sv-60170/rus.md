# Об утверждении перечня видов деятельности, технологически связанных с регулируемыми услугами (товарами, работами) аэропортов

В соответствии с пунктом 1-1 статьи 18-1 Закона Республики Казахстан от 9 июля 1998 года "О естественных монополиях" ПРИКАЗЫВАЕМ:

> *Сноска. Преамбула в редакции совместного приказа Министра по инвестициям и развитию РК от 15.06.2017 № 354 и Министра национальной экономики РК от 22.05.2017 № 207 (вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования).*

1\. Утвердить прилагаемый перечень видов деятельности, технологически связанных с регулируемыми услугами (товарами, работами) аэропортов.

2\. Департаменту по регулированию в сфере железнодорожного транспорта, гражданской авиации и портов Агентства Республики Казахстан по регулированию естественных монополий (Ибраева Г.К.) в установленном законодательством Республики Казахстан порядке обеспечить представление настоящего приказа в Министерство юстиции Республики Казахстан для государственной регистрации.

3\. Департаменту административной работы Агентства Республики Казахстан по регулированию естественных монополий (Сулейменова Р.Е.) после государственной регистрации настоящего приказа в Министерстве юстиции Республики Казахстан:

1) обеспечить в установленном законодательством порядке его официальное опубликование в средствах массовой информации, с последующим представлением в Юридический Департамент (Мукушева М.Ш.) сведений об опубликовании;

2) довести его до сведения структурных подразделений и территориальных органов Агентства Республики Казахстан по регулированию естественных монополий.

4\. Контроль за исполнением настоящего приказа возложить на заместителя Председателя Агентства Республики Казахстан по регулированию естественных монополий Смагулова К.М. и вице-министра транспорта и коммуникаций Республики Казахстан Бектурова А.Г.

5\. Настоящий приказ вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

## Перечень видов деятельности, технологически связанных с регулируемыми услугами (товарами, работами) аэропортов

1\. Обслуживание пассажиров.

2\. Досмотр и обеспечение пропусками сотрудников и транспортных средств сторонних организаций, проходящих в зону ограниченного доступа.

3\. Обеспечение содержания дорог для въезда транспортных средств.

4\. Противопожарное обеспечение в районе аэропорта сторонним организациям.

5\. Предоставление залов длительного пребывания для пассажиров, членов экипажа.

<a id="p6"></a>

6\. Обработка груза.

<a id="p7"></a>

7\. Хранение груза свыше двадцати четырех часов.

<a id="p8"></a>

8\. Обеспечение авиационными горюче-смазочными материалами воздушного судна.

<a id="p9"></a>

9\. Услуги по хранению горюче-смазочных материалов и спецжидкостей сторонним организациям.

<a id="p10"></a>

10\. Обслуживание воздушного судна по транзитной форме технического обслуживания.

<a id="p11"></a>

11\. Обеспечение встречи- выпуска воздушного судна.

<a id="p12"></a>

12\. Посадка/высадка пассажиров.

<a id="p13"></a>

13\. Доставка пассажиров.

<a id="p14"></a>

14\. Доставка экипажа.

<a id="p15"></a>

15\. Обеспечение пассажиров и экипажа воздушного судна бортовым питанием.

<a id="p16"></a>

16\. Персональное обслуживание и сопровождение пассажиров, в том числе в контролируемой зоне.

<a id="p17"></a>

17\. Персональное сопровождение багажа, грузов и почты.

<a id="p18"></a>

18\. Буксировка.

<a id="p19"></a>

19\. Внутренняя уборка.

<a id="p20"></a>

20\. Обслуживание санузлов (туалетов) воздушных судов.

<a id="p21"></a>

21\. Заправка питьевой водой.

<a id="p22"></a>

22\. Подача электроэнергии к воздушному судну.

<a id="p23"></a>

23\. Кондиционирование воздушного судна.

<a id="p24"></a>

24\. Очистка от снега и льда воздушного судна.

<a id="p25"></a>

25\. Заправка авиадвигателей маслом.

<a id="p26"></a>

26\. Заправка системы кислородом.

<a id="p27"></a>

27\. Заправка воздушного судна азотом или сжатым воздухом.

<a id="p28"></a>

28\. Проверка и дозаправка гидросистемы.

<a id="p29"></a>

29\. Обеспечение воздушного запуска авиадвигателей.

<a id="p30"></a>

30\. Стоянка в ангаре.

<a id="p31"></a>

31\. Штурманское обеспечение полетов.

<a id="p32"></a>

32\. Предоставление навигационных расчетов.

<a id="p33"></a>

33\. Составление флайт-планов.

<a id="p34"></a>

34\. Аренда сборников аэронавигационной информации.

<a id="p35"></a>

35\. Аренда радионавигационных карт.

<a id="p36"></a>

36\. Расчет потребного количества авиационного горюче-смазочного материала с учетом прогнозируемого ветра.

<a id="p37"></a>

37\. Предполетный медицинский осмотр членов экипажа.

<a id="p38"></a>

38\. Вывоз и утилизация мусора с воздушного судна.

<a id="p39"></a>

39\. Санитарная обработка съемного оборудования и бортовой посуды по каждому типу воздушного судна.

<a id="p40"></a>

40\. Предоставление технического персонала (оператора).

<a id="p41"></a>

41\. Предоставление специальных технических и транспортных средств.

<a id="p42"></a>

42\. Предоставление метеорологического обеспечения заказным (чартерным) авиарейсам.

<a id="p43"></a>

43\. Предсменный медицинский осмотр сторонним организациям, участвующим в процессе обеспечения авиаперевозок.

<a id="p44"></a>

44\. Упаковка багажа.

<a id="p45"></a>

45\. Осмотр на пригодность ветродрома сторонним организациям, находящимся в районе аэродрома.

<a id="p46"></a>

46\. Техническое и линейное обслуживание воздушного судна.

<a id="p47"></a>

47\. Техническое обслуживание и ремонт авиационной техники.

<a id="p48"></a>

48\. Услуга по изготовлению и реализации азота, кислорода, сжатого воздуха и ремонт баллонов.

<a id="p49"></a>

49\. Метрологические услуги по поверки оборудования.

<a id="p50"></a>

50\. Сопровождение воздушного судна.

<a id="p51"></a>

51\. Очистка ветродрома сторонних организаций, находящихся на территории аэропорта.

<a id="p52"></a>

52\. Пользование объектами инфраструктуры аэропорта, в разрезе комплекса аэродрома.

<a id="p53"></a>

53\. Аварийно-спасательное обеспечение вертолетов вне аэродрома.
