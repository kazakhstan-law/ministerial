# Судьяның кәсiптiк мiндеттерiн атқаруына кедергi келтiретiн аурулардың тiзбесiн бекіту туралы

"Қазақстан Республикасының сот жүйесi мен судьяларының мәртебесi туралы" Қазақстан Республикасының Конституциялық заңына өзгерiстер мен толықтырулар енгiзу туралы" Қазақстан Республикасы Конституциялық заңын іске асыру мақсатында БҰЙЫРАМЫЗ:

<a id="p1"></a>

1. Судьяның кәсiптiк мiндеттерiн атқаруына кедергi келтiретiн аурулардың тiзбесi бекітілсін.

<a id="p2"></a>

2. Судья лауазымына үміткерлерді медициналық ұйымдар медициналық куәландыру жүргізу кезінде осы бұйрықты басшылыққа алсын.

<a id="p3"></a>

3. Қазақстан Республикасы Жоғары Соты жанындағы Сот әкімшілігі жөніндегі комитеті Қазақстан Республикасының Әділет біліктілік алқасына және Қазақстан Республикасының Жоғары Сот Кеңесіне осы бұйрықты қолдану үшін жіберсін.

<a id="p4"></a>

4. Осы бұйрықтың орындалуын бақылау Қазақстан Республикасының Қазақстан Республикасы Жоғары Соты жанындағы Сот әкімшілігі жөніндегі комитет төрағасының орынбасары М.Т.Таймерденовке және Қазақстан Республикасы Денсаулық сақтау министрлігінің вице-министрі К.Т.Омаровқа жүктелсiн.

<a id="p5"></a>

5. Қазақстан Республикасы Жоғары Соты жанындағы Сот әкімшілігі жөніндегі комитеті осы бұйрықты Қазақстан Республикасы Әдiлет министрлiгiне мемлекеттiк тiркеуге заңнамада белгiленген тәртiппен ұсынылсын және бұқаралық ақпарат құралдарында ресми жариялауды қамтамасыз етсін.

<a id="p6"></a>

6. Осы бұйрық ресми жарияланған күнiнен бастап он күнтiзбелiк күн өткеннен кейiн қолданысқа енгiзiледi.

> *Қазақстан Республикасы*  
> *Жоғары Соты жанындағы*  
> *Сот әкімшілігі жөніндегі*  
> *комитет төрағасы*

> *Қазақстан Республикасы*  
> *Денсаулық сақтау*  
> *министрлігінің министрі*

> *Қазақстан Республикасы Жоғары Соты жанындағы Сот әкімшілігі жөніндегі комитеті төрағасының 2007 жылдағы 17 қаңтардағы N 15-П, Қазақстан Республикасы Денсаулық сақтау Министрінің 2007 жылдағы»17 қаңтардағы N 18 Бірлескен бұйрығымен бекітілген*

## Судьяның кәсіби міндеттерін атқаруына кедергі келтіретін аурулардың тізбесі

<a id="an0_p1"></a>

1. Айқын қимыл бұзылулары бар экстрапирамидалық құрылымдары айрықша зақымданған нерв жүйесі аурулары.

<a id="an0_p2"></a>

2. Пирамидалық және мишықтық жүйенің айрықша зақымданған нерв жүйесі аурулары.

<a id="an0_p3"></a>

3. Сирингомиелия және сирингобульбия.

<a id="an0_p4"></a>

4. Бүйірлік амиотрофикалық склероз.

<a id="an0_p5"></a>

5. Когнитивтік функциялары (Альцгеймер, Пик аурулары және басқалар) айрықша бұзылған дегенеративтік аурулар.

<a id="an0_p6"></a>

6. Эпилепсия және әртүрлі этилогияның эпилепсиялық синдромдары.

<a id="an0_p7"></a>

7. Жайылма склероз.

<a id="an0_p8"></a>

8. Диффузиялы склероз (Шильдер лейкоэнцефалиті мен басқалар).

<a id="an0_p9"></a>

9. Функциясы тұрақты бұзылған нерв-бұлшық ет аурулары.

<a id="an0_p10"></a>

10. Инсульт, тұрақты қимыл және сезімталдық бұзылуы мен жоғары психикалық функциялары бұзылуының салдары.

<a id="an0_p11"></a>

11. Функциясы тұрақты бұзылған мынадай эндокриндік жүйе аурулары:

    туа біткен йод жетіспеушілігі белгісі;

    диффузиялы зобы бар туа біткен гипотериоз;

    туа біткен зобсыз гипотериаз;

    ІІІ-ІV дәрежедегі эндокриндік офтальмопатиясымен ауыр нысандағы жайылмалы зобы бар тиреотоксикоз;

    1 типті инсулинге тәуелді қант диабеті, ауыр нысанды, құбылмалы ағымдағы;

    ауырлығы орта және ауыр нысандағы акромегалия, белсенді сатысы және гипофизарлы ірілік;

    ауырлығы орташа және ауыр нысандағы Иценко-Кушинг ауруы, Нельсон синдромы;

    альвеолярлы гиповентиляциямен ілесе жүретін, семірудің ең соңғы дәрежесі;

    толық гипопитуитаризм, ауыр нысаны, құбылмалы ағымы;

    гипофизді нанизм;

    функциясы тұрақты бұзылған эндокриндік органдардың ісіктері.

<a id="an0_p12"></a>

12. Орталық нерв жүйесінің функциялары айқын бұзылған қатерсіз ісіктері.

<a id="an0_p13"></a>

13. Гемобластоздар:

    көкбауырдың эритермиядан кейінгі миелоидты метаплазасы бар эритермия;

    акселерация мен бласты криз сатысындағы созылмалы миелолейкоз;

    тұрақты анемиямен ілесе жүретін созылмалы лимфолейкоз;

    лимфогрануломатоз (іс жүзінде сауыққандарды қоспағанда);

    жіті лейкоз (іс жүзінде сауыққандарды қоспағанда);

    көптік миелома (2-3 дәрежесі);

    гемофилия;

    Вилли-Бранда ауруы;

    идиопатиялық тромбоцитопениялық пурпура (тиімсіз спленэктомия кезінде);

    Рандю-Ослер ауруы (геморрагиялық синдром кезінде);

    тұқым қуалайтын тромбоцитопатиялар (геморрагия болған жағдайда).

<a id="an0_p14"></a>

14. Геморрагиялық диатездер.

<a id="an0_p15"></a>

15. ІІІ дәрежелі қан айналым қызметінің жеткіліксіздігі (ҚЖ) бар жүрек және жүрекқаптың созылмалы аурулары.

<a id="an0_p16"></a>

16. Жүректің ишемиялық ауруы: стенокардияның жиі ұстамалары (функциялық класс (ФК) ІІІ-ІV).

<a id="an0_p17"></a>

17. ІІІ сатыдағы гипертониялық ауру.

<a id="an0_p18"></a>

18. Ырғақтың бұзылуымен ілесе жүретін жүрек аурулары:

    ЖҚЖ 1 минутта кемінде 50 немесе естен тану жағдайларымен ілесе жүретін синустық түйін, А-В блокадалар функциясының бұзылуы;

    ұстамалы қарынша тахикардиясы, қарынша экстрасистолия (Лаун бойынша ІІІ-ІV);

    ЭКГ-да QT интервалын 440 миллисекундтан аса ұзарту.

<a id="an0_p19"></a>

19. Қолқа мен артерияның кез-келген бөлімдерінің аневризмдері мен қатпарлануы.

<a id="an0_p20"></a>

20. Барлық сатыдағы реваматоидт артриті.

<a id="an0_p21"></a>

21. Жүйелік қызыл жегі, барлық сатысының созылмалы нысандары.

<a id="an0_p22"></a>

22. Жүйелік склеродермия, барлық сатыдағы үдемелі жүйелік склероздың перифериялы және висцералды нысандары.

<a id="an0_p23"></a>

23. 2-3-дәрежедегі бүйрек қызметінің жеткіліксіздігі бар созылмалы гепатиттің айқын нысандары.

<a id="an0_p24"></a>

24. Порталды гипертензиясы бар бауыр циррозы.

<a id="an0_p25"></a>

25. Іш өту синдромы мен жиі қан кетуі бар тоқ ішектің тұқымында бар диффузиялы полипозы.

<a id="an0_p26"></a>

26. Крон ауруы және жиі асқынулары мен қайталаған қан кетулері бар басқа да тән емес колиттер.

<a id="an0_p27"></a>

27. 2-3 сатылы созылмалы бүйрек қызметінің жеткіліксіздігі бар (СБЖ) созылмалы бүйрек аурулары.

<a id="an0_p28"></a>

28. Вестибулярлы қызметтің бұзылуы, оның ішінде Меньер ауруы.

<a id="an0_p29"></a>

29. Бір және екі жақты естуді электроакустикалық түзетумен (есту аппараттарын кем дегенде 6 метрден сыбырлап сөйлеуді қабылдау деңгейіне дейін таңдау) жақсарту мүмкін болмаған жағдайда оның кез-келген этиологиясының тұрақты төмендеуі.

<a id="an0_p30"></a>

30. Көздің көрмеуі.

<a id="an0_p31"></a>

31. Ауыр тұрақты немесе жиі асқынатын ауырсыну құбылыстары бар созылмалы және ұзаққа созылған психикалық бұзылулар.

<a id="an0_p32"></a>

32. Маскүнемдік, нашақорлық, уытқұмарлық.

<a id="an0_p33"></a>

33. Псориаз, күлдіреуік, ихтиоз нысанындағы дерматоздар ауыр нысандары.
