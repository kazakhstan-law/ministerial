# Об утверждении Правил выплаты денежной компенсации в размере стоимости общевойскового пайка при отсутствии возможности обеспечения питанием по установленным нормам основных продовольственных пайков военнослужащим по контракту Вооруженных Сил Республики Казахстан

В соответствии с пунктом 7 статьи 44 Закона Республики Казахстан от 16 февраля 2012 года «О воинской службе и статусе военнослужащих» ПРИКАЗЫВАЮ:

<a id="p1"></a>

1. Утвердить прилагаемые Правила выплаты денежной компенсации в размере стоимости общевойскового пайка при отсутствии возможности обеспечения питанием по установленным нормам основных продовольственных пайков военнослужащим по контракту Вооруженных Сил Республики Казахстан.

<a id="p2"></a>

2. Управлению начальника Тыла и вооружения Вооруженных Сил Республики Казахстан обеспечить:

   1) государственную регистрацию настоящего приказа в Министерстве юстиции Республики Казахстан;

   2) направление копии настоящего приказа в Республиканское государственное предприятие на праве хозяйственного ведения «Республиканский центр правовой информации» для включения и официального опубликования в Эталонном контрольном банке нормативных правовых актов Республики Казахстан в бумажном и электронном видах в течение десяти календарных дней со дня государственной регистрации;

   3) размещение настоящего приказа на интернет-ресурсе Министерства обороны Республики Казахстан после его официального опубликования;

   4) направление сведений в Юридический департамент Министерства обороны Республики Казахстан об исполнении мероприятий, предусмотренных подпунктами 1), 2) и 3) настоящего пункта в течение десяти календарных дней со дня государственной регистрации.

<a id="p3"></a>

3. Контроль за исполнением приказа возложить на заместителя Министра обороны Республики Казахстан генерал-майора Жанжуменова Т.Ж.

<a id="p4"></a>

4. Настоящий приказ довести до должностных лиц в части, их касающейся.

<a id="p5"></a>

5. Настоящий приказ вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

**Министр обороны Республики Казахстан Генерал-полковник**

**С. Жасузаков**

> *Утверждены*  
> *приказом Министра обороны*  
> *Республики Казахстан*  
> *от 8 августа 2017 года № 431*

# Правила выплаты денежной компенсации в размере стоимости общевойскового пайка при отсутствии возможности обеспечения питанием по установленным нормам основных продовольственных пайков военнослужащим по контракту Вооруженных Сил Республики Казахстан

<a id="an0_p1"></a>

1. Настоящие Правила выплаты денежной компенсации в размере стоимости общевойскового пайка при отсутствии возможности обеспечения питанием по установленным нормам основных продовольственных пайков военнослужащим по контракту Вооруженных Сил Республики Казахстан (далее - Правила) определяют порядок выплаты денежной компенсации в размере стоимости общевойскового пайка при отсутствии возможности обеспечения питанием по установленным нормам основных продовольственных пайков военнослужащим по контракту.

<a id="an0_p2"></a>

2. Выплата денежной компенсации производится в целях возмещения расходов военнослужащих на питание, которые в соответствии с пунктом 7 статьи 44 Закона Республики Казахстан «О воинской службе и статусе военнослужащих» обеспечиваются питанием за счет государства.

   В случае нахождения военнослужащего по контракту в служебной командировке выплата денежной компенсации взамен пайка не осуществляется.

<a id="an0_p3"></a>

3. Выплата денежной компенсации осуществляется за счет средств республиканского бюджета, предусмотренных на содержание государственного органа.

<a id="an0_p4"></a>

4. Перечень воинских частей (подразделений), учреждений Вооруженных Сил Республики Казахстан, в которых не осуществляется организация питания (далее – Перечень) формируется по форме согласно приложению к настоящим Правилам управлением обеспечения продовольствием Главного управления Тыла Управления начальника Тыла и вооружения Вооруженных Сил Республики Казахстан.

   Перечень утверждается заместителем Министра обороны Республики Казахстан по кураторству и рассылается в государственные учреждения Вооруженных Сил Республики Казахстан не позднее 20 декабря года, предшествующему году выплаты денежной компенсации.

<a id="an0_p5"></a>

5. Выплата денежной компенсации производится на основании приказа руководителя государственного учреждения, в котором военнослужащий по контракту проходит службу. В приказе указывается сумма денежной компенсации за месяц на каждого военнослужащего по контракту.

<a id="an0_p6"></a>

6. Для выплаты денежной компенсации военнослужащий по контракту с 1 по 5 число месяца, следующего за отчетным месяцем, подает рапорт на имя руководителя государственного учреждения с приложением выписки из приказов по строевой части, подтверждающей исполнение военнослужащим по контракту обязанностей воинской службы, при которых в случаях, предусмотренных законодательством, ему полагалось обеспечение питанием за счет государства.

<a id="an0_p7"></a>

7. Выплата компенсации производится одновременно с выплатой денежного довольствия по месту прохождения воинской службы в текущем месяце за истекший месяц.

<a id="an0_p8"></a>

8. Перечисление компенсации осуществляется по месту прохождения воинской службы, на текущие счета получателей, открытые в организациях, имеющих лицензию на проведение отдельных видов банковских операций.

<a id="an0_p9"></a>

При служебном перемещении военнослужащего по контракту из одного государственного учреждения в другое, выплата компенсации в месяц убытия к новому месту прохождения воинской службы осуществляется по прежнему месту прохождения воинской службы.
