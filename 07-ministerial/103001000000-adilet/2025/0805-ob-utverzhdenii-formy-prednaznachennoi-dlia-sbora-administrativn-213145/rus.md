# Об утверждении формы, предназначенной для сбора административных данных на безвозмездной основе «Форма отчета о количестве лицензионных договоров с пользователями, заключенных организациями, управляющими имущественными правами на коллективной основе»

В соответствии с подпунктом 2) пункта 3 статьи 16 Закона Республики Казахстан «О государственной статистике» ПРИКАЗЫВАЮ:

1. Утвердить форму, предназначенную для сбора административных данных на безвозмездной основе «Форма отчета о количестве лицензионных договоров с пользователями, заключенных организациями, управляющими имущественными правами на коллективной основе» согласно приложению к настоящему приказу.

2. Департаменту стратегического планирования и организационно-аналитической работы в установленном законодательством порядке обеспечить государственную регистрацию настоящего приказа и размещение настоящего приказа на официальном интернет-ресурсе Министерства юстиции Республики Казахстан.

3. Контроль за исполнением настоящего приказа возложить на Руководителя Аппарата Министерства юстиции Республики Казахстан.

4. Настоящий приказ вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

Пояснение по заполнению формы, предназначенной для сбора административных данных на безвозмездной основе «Сведения о количестве лицензионных договоров с пользователями, заключенных организациями, управляющими имущественными правами на коллективной основе»

(Форма ИС-1, годовая)

1. Настоящее пояснение определяет требования по заполнению формы, предназначенной для сбора административных данных на безвозмездной основе «Сведения о количестве лицензионных договоров с пользователями, заключенных организациями, управляющими имущественными правами на коллективной основе» (далее – Форма).

2. Основной задачей ведения данной Формы является определение количества лицензионных договоров с пользователями, заключенных организациями, управляющими имущественными правами на коллективной основе.

3. Форма заполняется сотрудником организации, управляющей имущественными правами на коллективной основе.

4. Форма заполняется следующим образом:

   в графе 3 строки 1 указывается общее количество лицензионных договоров с пользователями, заключенных организацией управляющими правами на коллективной основе;

   в графе 3 строки 2 указывается количество договоров с пользователями, заключенных организацией управляющими правами на коллективной основе, в отчетный период;

   в графе 3 строки 3 указывается количество договоров с пользователями, расторгнутых организацией управляющими правами на коллективной основе, в отчетный период.
