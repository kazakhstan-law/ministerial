## Пояснение по заполнению формы предназначенной для сбора административных данных «Сведения о градации по годам назначения пенсий без учета получателей силовых структур»

### 1. Общие положения

<a id="an12_p1"></a>

1. Н астоящее Пояснение определяет единые требования по заполнению формы по градации по годам назначения пенсий без учета получателей силовых структур (далее – Форма).

<a id="an12_p2"></a>

2. Форма заполняется и предоставляется Государственной корпорацией «Правительство для граждан» (далее – Государственная корпорация) по запросу 1 раз в год.

<a id="an12_p3"></a>

3. Форму подписывает ответственное лицо Государственной корпорации, а в случае его отсутствия, лицо, выполняющее его обязанности.

### 2. Пояснение по заполнению формы

<a id="an12_p4"></a>

4. В графе «Размер пенсии с шагом в 100 тенге» указываются размер пенсии в диапазоне 100 тенге

<a id="an12_p5"></a>

5. В графе «Всего» указывается количество получателей пенсионных выплат в данном диапазоне.

<a id="an12_p6"></a>

6. В графе «По году назначения» указывается численность получателей пенсии по годам.

<a id="an12_p7"></a>

7. В графах «от» и «до» указывается размер пенсионной выплаты.
