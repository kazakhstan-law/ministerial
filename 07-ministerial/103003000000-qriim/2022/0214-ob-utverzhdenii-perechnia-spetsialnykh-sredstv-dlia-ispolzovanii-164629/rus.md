# Об утверждении Перечня специальных средств для использования работниками частных охранных организаций

В соответствии с пунктом 2 статьи 18 Закона Республики Казахстан «Об охранной деятельности», ПРИКАЗЫВАЮ:

<a id="p1"></a>

1. Утвердить прилагаемый Перечень специальных средств для использования работниками частных охранных организаций.

<a id="p2"></a>

2. Департаменту по контролю за охранной деятельностью Министерства внутренних дел Республики Казахстан в установленном законодательством Республики Казахстан порядке обеспечить:

   1) государственную регистрацию настоящего приказа в Министерстве юстиции Республики Казахстан;

   2) размещение настоящего приказа на интернет-ресурсе Министерства внутренних дел Республики Казахстан;

   3) в течение десяти рабочих дней после государственной регистрации настоящего приказа в Министерстве юстиции Республики Казахстан представление в Юридический департамент Министерства внутренних дел Республики Казахстан сведений об исполнении мероприятий, предусмотренных подпунктами 1) и 2) настоящего пункта.

<a id="p3"></a>

3. Контроль за исполнением настоящего приказа возложить на курирующего заместителя министра внутренних дел Республики Казахстан.

<a id="p4"></a>

4. Настоящий приказ вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

**Министр внутренних дел Республики Казахстан**

**Е. Тургумбаев**

> *Утвержден приказом*  
> *Министра внутренних дел*  
> *Республики Казахстан*  
> *от 14 февраля 2022 года № 64*

## Перечень специальных средств для использования работниками частных охранных организаций

<a id="an1_p1"></a>

1. Резиновые палки.

<a id="an1_p2"></a>

2. Жилет защитный 1-5-го классов защиты.

<a id="an1_p3"></a>

3. Шлем защитный 1-3-го классов защиты.

<a id="an1_p4"></a>

4. Наручники.

<a id="an1_p5"></a>

5. Комплект защитных щитков, для защиты рук и ног.

<a id="an1_p6"></a>

6. Детекторы обнаружения оружия, взрывных веществ и устройств.

<a id="an1_p7"></a>

7. Детекторы обнаружения радиоактивных, химических и отравляющих веществ.

<a id="an1_p8"></a>

8. Системы охранной, тревожной сигнализации.

<a id="an1_p9"></a>

9. Системы контроля и управления доступа.

<a id="an1_p10"></a>

10. Видеоконтрольные и видеоохранные системы телевизионного наблюдения, не относящиеся к технике двойного применения.

<a id="an1_p11"></a>

11. Системы передачи извещения, в том числе и по радиоканалам.

<a id="an1_p12"></a>

12. Портативный носимый видеорегистратор.
