# Об утверждении Правил направления осужденных в учреждения уголовно-исполнительной системы для отбывания наказания

В соответствии с подпунктом 4) статьи 16 Уголовно-исполнительного кодекса Республики Казахстан от 5 июля 2014 года ПРИКАЗЫВАЮ:

<a id="p1"></a>

1. Утвердить прилагаемые Правила направления осужденных в учреждения уголовно-исполнительной системы для отбывания наказания.

<a id="p2"></a>

2. Комитету уголовно-исполнительной системы Министерства внутренних дел Республики Казахстан (Бердалин Б.М.) обеспечить:

   1) государственную регистрацию настоящего приказа в Министерстве юстиции Республики Казахстан;

   2) в установленном порядке официальное опубликование настоящего приказа в информационно-правовой системе "Әділет" и официальных средствах массовой информации;

   3) размещение настоящего приказа на интернет-ресурсе Министерства внутренних дел Республики Казахстан.

<a id="p3"></a>

3. Контроль за исполнением настоящего приказа возложить на заместителя министра внутренних дел Республики Казахстан полковника полиции Бисенкулова Б.Б. и Комитет уголовно-исполнительной системы Министерства внутренних дел Республики Казахстан (Бердалин Б.М.).

<a id="p4"></a>

4. Настоящий приказ подлежит официальному опубликованию и вводится в действие с 1 января 2015 года.

## Правила направления осужденных в учреждения уголовно-исполнительной системы для отбывания наказания

## Общие положения

<a id="an0_p1"></a>

1. Настоящие Правила направления осужденных в учреждения уголовно- исполнительной системы (далее - УИС) для отбывания наказания определяют порядок направления осужденных для отбывания наказания в учреждения УИС (далее - учреждения) в соответствии с требованиями статьи 90 Уголовно-исполнительного кодекса Республики Казахстан (далее - УИК).

<a id="an0_p2"></a>

2. Направление осужденных к лишению свободы для дальнейшего отбывания наказания в учреждения осуществляется на основании письменного указания (наряда) Комитета уголовно-исполнительной системы Министерства внутренних дел Республики Казахстан (далее - Комитет УИС).

<a id="an0_p3"></a>

3. Осужденные к лишению свободы направляются в учреждение с учетом условий, необходимых для их исправления, поддержания социально полезных связей, обеспечения безопасности и предупреждения совершения ими новых правонарушений.

<a id="an0_p4"></a>

4. Направление осужденного для отбывания наказания в учреждение соответствующего вида режима другой области допускается по решению уполномоченного органа УИС в случаях, предусмотренных частью 3 статьи 88 УИК.

<a id="an0_p5"></a>

5. Согласно пункту 2 статьи 17 УИК территориальный орган УИС направляет осужденных в учреждения, закрепленные уполномоченным органом уголовно-исполнительной системы за территориальным органом;

<a id="an0_p6"></a>

6. Направление осужденных в учреждения осуществляются только по указаниям (нарядам) Комитета УИС.

<a id="an0_p7"></a>

7. Осужденные, направленные в учреждения по указаниям (нарядам) Комитета УИС, не могут быть в дальнейшем направлены в другие учреждения без его (Комитета УИС) разрешения.

<a id="an0_p8"></a>

8. Указания (наряды) Комитета УИС готовятся отделом специального учета Комитета УИС и направляются на исполнение территориальным органам УИС.

<a id="an0_p9"></a>

9. Указания (наряды) подписываются:

   1) председателем (или лицо, исполняющее его обязанности) Комитета УИС;

   2) заместителем председателя Комитета УИС.

<a id="an0_p10"></a>

10. Лица, осужденные на срок свыше пяти лет за совершение особо тяжких преступлений, при опасном рецидиве преступлений с отбыванием наказания в тюрьме, а также лица, в отношении которых приговор о смертной казни вступил в силу до введения моратория или во время действия моратория на исполнение смертной казни, направляются в учреждения полной безопасности.

<a id="an0_p11"></a>

11. Осужденные из учреждений чрезвычайной, максимальной и средней безопасности в учреждения минимальной безопасности направляются на основании указаний Комитета УИС с учетом условий, необходимых для поддержания социально-полезных связей.

<a id="an0_p12"></a>

12. При нарушении порядка отбывания наказания в учреждении минимальной безопасности, осужденные возвращаются в то учреждение, откуда они были направлены.

<a id="an0_p13"></a>

13. Осужденные при опасном рецидиве преступлений, к пожизненному лишению свободы, к отбыванию наказания в учреждении полной безопасности, которым наказание в виде смертной казни в порядке помилования заменено лишением свободы, осужденные женщины, осужденные несовершеннолетние направляются для отбывания наказания по месту нахождения соответствующих учреждений.

<a id="an0_p14"></a>

14. Несовершеннолетние осужденные, отрицательно характеризующиеся и достигшие в период отбывания наказания восемнадцатилетнего возраста, согласно постановлению суда из учреждений средней безопасности для содержания несовершеннолетних направляются в учреждение смешанной безопасности, из которого они прибыли для дальнейшего направления в учреждения соответствующего вида режима согласно закреплению.

    Осужденные к лишению свободы, достигшие восемнадцатилетнего возраста, с их согласия оставляются в учреждении, но не более чем до достижения ими двадцати одного года. Решение об оставлении осужденных, достигших восемнадцатилетнего возраста, в учреждении принимается судом на основании представления начальника учреждения.

<a id="an0_p15"></a>

15. Осужденные направляются для отбывания наказания в учреждения не позднее десяти календарных дней со дня получения администрацией учреждения смешанной безопасности распоряжения суда об исполнении приговора, вступившего в законную силу.

<a id="an0_p16"></a>

16. Администрация учреждения смешанной безопасности в течение двух рабочих дней направляет письменное уведомление супругу (супруге) либо одному из родственников либо иному лицу по выбору осужденного о том, куда он направляется для отбывания наказания.

<a id="an0_p17"></a>

17. Осужденные к лишению свободы перемещаются из одного места отбывания наказания в другое под конвоем.
