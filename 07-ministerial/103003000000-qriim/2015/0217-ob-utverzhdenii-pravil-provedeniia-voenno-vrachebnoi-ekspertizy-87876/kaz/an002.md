> *Қазақстан Республикасы*  
> *Ұлттық ұланының әскери-дәрігерлік*  
> *сараптама өткізу қағидаларына*  
> *2-қосымша*

> *Нысан*

```
  Фотосуретке арналған орын
     (әскери бөлімінің
        елтаңба мөрі)
           Әскери оқу орнына түсетін азаматтың медициналық куәландыру картасы
```

```
  1. Тегі, аты, әкесінің аты бар болса, туған жылы ___________________________________
  ____________________________________________________________________________________
  ____________________________________________________________________________________
  әскери қызметшіге (әскери атағын жазу)
```

```
  2. Тұрғылықты жері (мекенжайы) _____________________________________________________
                     (әскери қызметшілерге мекенжайы мен әскери бөлімнің шартты атауы)
  ____________________________________________________________________________________
  ____________________________________________________________________________________
```
