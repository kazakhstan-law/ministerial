## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`sec001`](kaz/sec001.md) | 1-Бөлім. Жалпы ережелер |
| [`sec003`](kaz/sec003.md) | 3-Бөлім. Республикалық бюджеттің шығыстар бойынша кассалық атқарылуы |
| [`sec005`](kaz/sec005.md) | 5-Бөлім. Өтеусіз негізде мемлекеттік бюджет |
| [`sec011`](kaz/sec011.md) | 11-Бөлім. Валюталық шоттар |
| [`sec013`](kaz/sec013.md) | 13-Бөлім. Қазақстан Республикасының республикалық |
| [`sec013-ch002`](kaz/sec013-ch002.md) | `!` 2-Тарау. Мемлекеттiк бюджеттiң кассалық атқарылуы туралы есептеменi жасау және ұсыну тәртiбi |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
