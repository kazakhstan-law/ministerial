# Об утверждении Инструкции по кассовому исполнению государственного бюджета Республики Казахстан

Приказываю:

1. Утвердить прилагаемую Инструкцию по кассовому исполнению государственного бюджета Республики Казахстан.

2. Признать утратившим силу приказ Министерства финансов Республики Казахстан от 19 марта 1997 года № 74 V970286_ "Об утверждении Временной Инструкции по кассовому исполнению республиканского и местных бюджетов".

3. Настоящий приказ вступает в силу с момента регистрации его в Министерстве юстиции Республики Казахстан.

```
Заместитель Премьер-Министра
Республики Казахстан - Министр финансов
```

```
Утверждена
приказом Министерства финансов
Республики Казахстан
от 7 сентября 1999г. № 484
```

Инструкция

по кассовому исполнению

государственного бюджета

Республики Казахстан


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`sec001`](rus/sec001.md) | Раздел 1. Общие положения |
| [`sec004`](rus/sec004.md) | Раздел 4. Кассовое исполнение местных бюджетов по расходам |
| [`sec011`](rus/sec011.md) | Раздел 11. Валютные счета |
| [`sec013`](rus/sec013.md) | Раздел 13. Порядок составления отчетов о кассовом |
| [`sec013-ch002`](rus/sec013-ch002.md) | `!` Глава 2. Порядок составления и представления отчетов о кассовом исполнении государственного бюджета |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
