# Об утверждении Плана счетов бухгалтерского учета государственных учреждений

В целях реализации пункта 3 статьи 116 Бюджетного кодекса Республики Казахстан, пункта 57 Перечня нормативных правовых актов Республики Казахстан, принятие которых необходимо в целях реализации Бюджетного кодекса, утвержденного распоряжением Премьер-Министра Республики Казахстан от 29 декабря 2008 года № 292-р "О мерах по реализации Бюджетного кодекса Республики Казахстан" ПРИКАЗЫВАЮ:

1. Утвердить прилагаемый План счетов бухгалтерского учета государственных учреждений.

2. Департаменту методологии бухгалтерского учета, аудиторской деятельности Министерства финансов Республики Казахстан (Тулеуов А.О.) обеспечить государственную регистрацию настоящего приказа в Министерстве юстиции Республики Казахстан и его официальное опубликование в установленном законодательством порядке.

3. Настоящий приказ вводится в действие с 1 января 2013 года.

**Министр**

**Б. Жамишев**


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |

| [`an001`](rus/an001.md) | План счетов бухгалтерского учета государственных учреждений |

| [`an003-t001-r001`](rus/an003-t001-r001.md) | `!` таблица 1, строки 1–313 |
| [`an003-t001-r002`](rus/an003-t001-r002.md) | таблица 1, строки 314–546 |
| [`an003-t002`](rus/an003-t002.md) | таблица 2 |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
