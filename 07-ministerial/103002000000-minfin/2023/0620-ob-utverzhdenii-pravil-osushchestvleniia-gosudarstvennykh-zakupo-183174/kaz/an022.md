## Конкурстық құжаттаманы түсіндіру жөнінде әлеуетті өнім берушілермен кездесу хаттамасы

```

```

          (олардың тегі, аты, әкесінің аты (бар болса), байланыс телефондарын көрсете отырып,

           ұйымдастырушының өзге де мамандары мен әлеуетті өнім берушілермен кездесуде
                 мемлекеттік сатып алуды ұйымдастырушыны білдірген, тартылған сарапшылар)
```

мынадай тұлғаларға:

```

```

          (олардың тегі, аты, әкесінің аты (бар болса), сондай-ақ конкурстық құжаттаманың
                ережелерін түсіндіру жөніндегі мемлекеттік сатып алуды ұйымдастырушымен
          кездесуде мұндай тұлғаның әлеуетті өнім берушіні білдіруге өкілеттігін растайтын
          құжатты көрсете отырып, мемлекеттік сатып алуды ұйымдастырушымен кездесуге

          (олардың тегі, аты, әкесінің аты (бар болса), байланыс телефондарын көрсете отырып,
            мемлекеттік сатып алуды ұйымдастырушының уәкілетті өкілінің, мемлекеттік сатып

   қайтарып алу және өзгерту туралы ақпарат, конкурсқа қатысуға өтінім құжаттарының

                    атауы, мекенжайы, олардың уәкілетті өкілдерінің тегі, аты, әкесінің аты (бар болса).
```

Конкурстық комиссия төрағасының, мүшелерінің және хатшысының тегі, аты, әкесінің аты (бар болса), қолдары.
