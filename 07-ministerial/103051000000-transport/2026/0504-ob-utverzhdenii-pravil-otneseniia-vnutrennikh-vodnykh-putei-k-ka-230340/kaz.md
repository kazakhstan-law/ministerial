# Iшкi су жолдарын кеме қатынасы санатына жатқызу қағидаларын және кеме қатынасы су жолдарының тізбесін бекіту туралы

«Қазақстан Республикасы Көлік министрлігінің кейбір мәселелері» Қазақстан Республикасы Үкіметінің 2023 жылғы 4 қазандағы № 862 қаулысымен бекітілген Қазақстан Республикасы Көлік министрлігі туралы ереженің 15-тармағының 281) тармақшасына сәйкес БҰЙЫРАМЫН:

<a id="p1"></a>

1. Мыналар:

   1) осы бұйрыққа 1-қосымшаға сәйкес Ішкі су жолдарын кеме қатынасы санатына жатқызу қағидалары;

   2) осы бұйрыққа 2-қосымшаға сәйкес Кеме қатынасы су жолдарының тізбесі бекітілсін.

<a id="p2"></a>

2. Қазақстан Республикасы Көлік министрлігінің Теміржол және су көлігі комитеті заңнамада белгіленген тәртіппен:

   1) осы бұйрық бекітілген күннен бастап күнтізбелік он күн ішінде оны қазақ және орыс тілдерінде электрондық нысанда Қазақстан Республикасы Нормативтік құқықтық актілерінің эталондық бақылау банкінде ресми жариялау және енгізу үшін «Қазақстан Республикасының Заңнама және құқықтық ақпарат институты» шаруашылық жүргізу құқығындағы республикалық мемлекеттік кәсіпорнына жіберуді;

   2) осы бұйрық ресми жарияланғаннан кейін оны Қазақстан Республикасы Көлік министрлігінің интернет-ресурсында орналастыруды қамтамасыз етсін.

<a id="p3"></a>

3. Осы бұйрықтың орындалуын бақылау жетекшілік ететін Қазақстан Республикасының Көлік вице-министріне жүктелсін.

<a id="p4"></a>

4. Осы бұйрық қол қойылған күнінен бастап күшіне енеді.

## Ішкі су жолдарын кеме қатынасы санатына жатқызу қағидалары

<a id="an1_p1"></a>

1. Осы Ішкі су жолдарын кеме қатынасы санатына жатқызу қағидалары (бұдан әрі – Қағидалар) Қазақстан Республикасы Үкіметінің 2023 жылғы 4 қазандағы № 865 қаулысымен бекітілген Қазақстан Республикасы Көлік министрлігі туралы ереженің 15-тармағының 281) тармақшасына сәйкес әзірленді және ішкі су жолдарын кеме қатынасы санатына жатқызу тәртібін айқындайды.

<a id="an1_p2"></a>

2. Осы Қағидаларда мынадай негізгі ұғымдар пайдаланылады:

   1) кеме қатынасы су жолдары – кеме қатынасы үшін ашық және Кеме қатынасы су жолдарының тізбесіне енгізілген ішкі су жолдары;

   2) Қазақстан Республикасының iшкi су жолдары (бұдан әрi – iшкi су жолдары) – кеме қатынасы мақсатында пайдалануға болатын табиғи немесе қолдан жасалған қатынас жолдары;

   3) уәкiлеттi орган – iшкi су көлiгi саласындағы басшылықты, сондай-ақ Қазақстан Республикасының заңнамасында көзделген шекте салааралық үйлестіруді жүзеге асыратын орталық атқарушы орган.

<a id="an1_p3"></a>

3. Ішкі су жолдарын кеме қатынасы санатына жатқызуды уәкілетті орган осы Қағидалардың 4-тармағына сәйкес жүргізілетін талдау негізінде, осы Қағидаларда көзделген шарттардың жиынтығы болған кезде, кеме қатынасы су жолдарының тізбесіне шекараларды көрсете отырып, ішкі су жолдарын немесе олардың учаскелерін міндетті түрде енгізе отырып жүзеге асырады.

<a id="an1_p4"></a>

4. Талдауды уәкілетті орган жүргізеді және ішкі су жолдарын кеме қатынасы санатына жатқызу туралы шешім қабылдау кезінде толық көлемде міндетті есепке алуға жатады және күтілетін тасымалдау көлемдерін, ішкі су жолының пайдалану сипаттамаларын, кеме қатынасы қауіпсіздігін қамтамасыз ету жөніндегі ұсыныстарды жиынтық бағалауды және оны күтіп-ұстауға арналған қаржы құралдарына қажеттілік негіздемесін қамтиды.

## Кеме қатынасы су жолдарының тізбесі

<a id="an2_p1"></a>

1. Балқаш көлі.

<a id="an2_p2"></a>

2. Есіл өзені, Петропавл су қоймасының бөгетінен бастап Солтүстік Қазақстан облысының Приишимка кентіне дейін.

<a id="an2_p3"></a>

3. Есіл өзенінің Астана қаласының әкімшілік-аумақтық шекарасы шегіндегі учаскесі.

<a id="an2_p4"></a>

4. Жайық-Каспий арнасы.

<a id="an2_p5"></a>

5. Қазақстан Республикасының аумағындағы Қиғаш өзенінің учаскесі (Волга өзенінің саласы).

<a id="an2_p6"></a>

6. Қара Ертіс өзені (Қытай Халық Республикасымен шекарадан бастап) Зайсан көлі – Бұқтырма, Өскемен және Шүлбі су қоймаларымен бірге Ертіс өзені (Ресей Федерациясымен шекараға дейін).

<a id="an2_p7"></a>

7. Ресей Федерациясынан бастап Жайық өзенінің сағасына дейінгі Жайық өзенінің учаскесі.

<a id="an2_p8"></a>

8. Іле өзені (Қытай Халық Республикасымен шекарадан бастап) – Қапшағай су қоймасы – Іле өзені (Балқаш көліне дейін).
