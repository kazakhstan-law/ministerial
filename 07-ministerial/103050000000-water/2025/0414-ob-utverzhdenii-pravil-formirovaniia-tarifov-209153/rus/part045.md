## Пояснение по заполнению формы, предназначенной для сбора административных данных на безвозмездной основе «Расчет коэффициента распределения общих основных средств по группе либо нематериальных активов» (индекс: 1-ОСНА, периодичность: қажеттігіне қарай)

### Глава 1. Общие положения

<a id="p1"></a>

1. Настоящее пояснение предназначено для подготовки субъектами естественной монополии расчета коэффициента распределения общих основных средств по группе либо нематериальных активов.

<a id="p2"></a>

2. При рассмотрений субъектами расчета коэффициента распределения общих основных средств по группе либо нематериальных активов, уполномоченный орган и субъекты естественной монополии руководствуются настоящими Правилами и нормативными правовыми актами, устанавливающими стандарты бухгалтерского учета, налоговым законодательством Республики Казахстан.

   Ответственность за полноту, обоснованность и достоверность расчетов, документов, информации и других материалов, несет субъект естественной монополии в соответствии с законами Республики Казахстан.

### Глава 2. Пояснение по заполнению формы

<a id="p3"></a>

3. в графе 1 указывается наименование показателя;

<a id="p4"></a>

4. в графе 2 указывается рабочее состояние (работает или в резерве);

<a id="p5"></a>

5. в графе 3 указывается остаточная стоимость на начало года всего, тысяч теңге;

<a id="p6"></a>

6. в графе 4 указывается наименование показателя для базы распределения (натуральный показатель);

<a id="p7"></a>

7. в графе 5 указывается значение показателя базы распределения, всего в натуральном показателе;

<a id="p8"></a>

8. в графах 6, 7, 8 указываются значение показателя базы распределения, по регулируемая услуга № 1;

<a id="p9"></a>

9. в графах 9, 10, 11 указываются значение показателя базы распределения, по регулируемая услуга № 2;

<a id="p10"></a>

10. в графах 12, 13, 14 указываются значение показателя базы распределения, по иным услугам.
