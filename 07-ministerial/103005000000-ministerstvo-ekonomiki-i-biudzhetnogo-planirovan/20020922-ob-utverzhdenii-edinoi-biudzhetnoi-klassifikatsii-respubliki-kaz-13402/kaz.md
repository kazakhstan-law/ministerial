# Қазақстан Республикасының Бірыңғай бюджеттік сыныптамасын бекіту туралы

Қазақстан Республикасы Президентінің "Қазақстан Республикасының мемлекеттік басқару жүйесін одан әрі жетілдіру шаралары туралы" 2002 жылғы 28 тамыздағы N 931 жарлығына сәйкес БҰЙЫРАМЫН:

1. Қазақстан Республикасының Бірыңғай бюджеттік сыныптамасы қосымшаға сәйкес бекітілсін.

2. Құқықтық және ұйымдастыру жұмыстары департаменті (Е.Е.Исаев) және Бюджет саясаты және жоспарлау департаменті (Б.Т.Сұлтанов) осы бұйрықтың Қазақстан Республикасының Әділет министрлігінде мемлекеттік тіркелуін қамтамасыз етсін.

3. Осы бұйрық Қазақстан Республикасының Әділет министрлігінде мемлекеттік тіркелген күнінен бастап қолданысқа енгізіледі.

Министр

> *жоспарлау министрінің*  
> *бұйрығына қосымша*  
> *2002 жылғы 23 қыркүйек N 3*


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`part001`](kaz/part001.md) | Қазақстан Республикасының Бірыңғай бюджеттік сыныптамасы |
| [`part001-part001`](kaz/part001-part001.md) | Шығыстардың экономикалық сыныптамасы |
| [`part001-part014`](kaz/part001-part014.md) | `!` Қолданылу мерзімінің аяқталуы |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
