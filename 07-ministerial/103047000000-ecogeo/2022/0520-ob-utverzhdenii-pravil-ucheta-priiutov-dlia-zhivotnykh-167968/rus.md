## Правила учета приютов для животных

### Глава 1. Общие положения

<a id="an1_p1"></a>

1. Настоящие Правила учета приютов для животных (далее – Правила) разработаны в соответствии с подпунктом 7) статьи 7 Закона Республики Казахстан «Об ответственном обращении с животными» (далее – Закон) и определяют порядок учета приютов для животных.

<a id="an1_p2"></a>

2. В настоящих Правилах используется следующие основные понятия и термины:

   1) приют для животных – имущественный комплекс, предназначенный и оборудованный для содержания животных, оказавшихся в положении, угрожающем их жизни и здоровью, безнадзорных и бродячих животных, а также изъятых или конфискованных у физических или юридических лиц домашних животных (животных-компаньонов);

   2) уполномоченный орган в области ответственного обращения с животными – центральный исполнительный орган, осуществляющий руководство и межотраслевую координацию в области ответственного обращения с животными;

   3) единая база данных по учету животных (далее – база данных) – электронная база данных, предусматривающая организационно-упорядоченную совокупность информационно-коммуникационных технологий, обслуживающего персонала и технической документации, предназначенная для регистрации животных, событий и действий по ним, соответсвующий доступ к которой предоставляется физическим и юридическим лицам.

<a id="an1_p3"></a>

3. Все действия, предусмотренные настоящими Правилами, осуществляемые приютами для животных регистрируется в базе данных, доступ к которой предоставляется на безвозмездной основе владельцам приютов для животных в соответствии с пунктом 1 статьи 11 Закона.

### Глава 2. Порядок учета приютов для животных

<a id="an1_p4"></a>

4. Внесение сведений в базу данных осуществляется владельцем приюта для животных с заполнением электронного заявления для постановки на учет.

<a id="an1_p5"></a>

5. Электронное заявление подается владельцем приюта для животных, с заверением своей электронной цифровой подписью.

<a id="an1_p6"></a>

6. Электронное заявление содержит следующие сведения:

   1) фамилия, имя, отчество (при его наличии), индивидуальный идентификационный номер физического лица, либо наименование и бизнес-идентификационный номер юридического лица, являющегося владельцем приюта для животных;

   2) наименование приюта для животных;

   3) адрес места расположения приюта для животных;

   4) вместимость приюта для животных;

   5) сведения об оснащенности приюта для животных;

   6) сведения о количестве специалистов приюта для животных;

   7) фактическая численность животных в приюте для животных.

<a id="an1_p7"></a>

7. Местный исполнительный орган района, области, города районного, областного, республиканского значения и столицы (далее – местный исполнительный орган) рассматривает приобщенные сведения в электронном заявлении владельца приюта для животных в течении 3 рабочих дней.

   В случае установления неполноты сведений, содержащихся в электронном заявлении местный исполнительный орган отказывает в рассмотрении заявления в базе данных.

<a id="an1_p8"></a>

8. В случае положительного рассмотрения электронного заявления местными исполнительными органами, приюту для животных в базе данных присваивается регистрационный номер (состоящий из четырнадцати символов), с указанием места расположения, которые имеют следующие обозначения:

   1) первые три символа – код Республики Казахстан, согласно коду ISO – Международной организации по стандартизации (три цифры – 398);

   2) с четвертого по пятые символы – числовой код обозначающий вид места содержания;

   3) с шестого по четырнадцатые символы – уникальный порядковый номер.

<a id="an1_p9"></a>

9. В случае прекращения деятельности по содержанию приюта для животных, владелец приюта для животных сообщает в местный исполнительный орган о принятом решении по прекращению полномочий, путем подачи электронного заявления в базу данных.
