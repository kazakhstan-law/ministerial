# Мемлекеттің қажеттілігін қамтамасыз етуге арналған биофармацевтикалық өнімдерді айқындау туралы

«Қазақстан Республикасының биологиялық қауіпсіздігі туралы» Қазақстан Республикасының Заңы 19-2-бабының 2-тармағына сәйкес БҰЙЫРАМЫН:

<a id="p1"></a>

1. Қоса беріліп отырған мемлекеттің қажеттілігін қамтамасыз етуге арналған биофармацевтикалық өнімдер бекітілсін.

<a id="p2"></a>

2. Қазақстан Республикасы Денсаулық сақтау министрлігінің Санитариялық-эпидемиологиялық бақылау комитеті Қазақстан Республикасының заңнамасында белгіленген тәртіппен:

   1) осы бұйрыққа қол қойылған күнінен бастап бес жұмыс күні ішінде оның қазақ және орыс тілдеріндегі электрондық түрдегі көшірмесін ресми жариялау және Қазақстан Республикасының Нормативтік құқықтық актілерінің эталондық бақылау банкіне енгізу үшін Қазақстан Республикасы Әділет министрлігінің «Қазақстан Республикасының Заңнама және құқықтық ақпарат институты» шаруашылық жүргізу құқығындағы республикалық мемлекеттік кәсіпорнына жіберуді;

   2) осы бұйрықты ресми жарияланғаннан кейін оны Қазақстан Республикасы Денсаулық сақтау министрлігінің интернет-ресурсында орналастыруды қамтамасыз етсін.

<a id="p3"></a>

3. Осы бұйрықтың орындалуын бақылау жетекшілік ететін Қазақстан Республикасының Денсаулық сақтау вице-министріне жүктелсін.

<a id="p4"></a>

4. Осы бұйрық алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Қазақстан Республикасы Денсаулық сақтау министрі**

**А. Альназарова**

## Мемлекеттің қажеттілігін қамтамасыз етуге арналған биофармацевтикалық өнімдер

<a id="an1_p1"></a>

1. Оба, тірі құрғақ вакцинасы.

<a id="an1_p2"></a>

2. Құрғақ, обаның антигенді эритроцитарлық диагностикумы.

<a id="an1_p3"></a>

3. Обаның антигенді эритроцитарлық диагностикумы ингредиенттерімен жиынтықта.

<a id="an1_p4"></a>

4. Құрғақ, обаның иммуноглобулинді эритроцитарлық диагностикумы.

<a id="an1_p5"></a>

5. Обаның иммуноглобулинді эритроцитарлық диагностикумы, ингредиенттерімен жиынтықта.

<a id="an1_p6"></a>

6. Обаның эритроцитарлық диагностикумдарына ингредиенттер.

<a id="an1_p7"></a>

7. Эритроцитарлы обалық липополисахаридті антигенді құрғақ диагностикум.

<a id="an1_p8"></a>

8. Құрғақ, Огава тырысқақтың иммуноглобулинді эритроцитарлық диагностикумы.

<a id="an1_p9"></a>

9. Құрғақ, Огава тырысқақтың иммуноглобулинді эритроцитарлық диагностикумына ингредиенттер.

<a id="an1_p10"></a>

10. Құрғақ, тырысқақтың О-139 антигендіэритроцитарлық диагностикумы.

<a id="an1_p11"></a>

11. Құрғақ, «О»-тырысқақтың иммуноглобулинді эритроцитарлық диагностикумы.

<a id="an1_p12"></a>

12. Құрғақ, «О»-тырысқақтың иммуноглобулинді эритроцитарлық диагностикумы, ингредиенттерімен жиынтықта.

<a id="an1_p13"></a>

13. Құрғақ «О»-тырысқақтың иммуноглобулинді эритроцитарлық диагностикумына ингредиенттер.

<a id="an1_p14"></a>

14. Құрғақ, тырысқақтың антигендіэритроцитарлық диагностикумы.

<a id="an1_p15"></a>

15. Құрғақ, туляремиялық эритроцитарлық иммуноглобулинді диагностикумы.

<a id="an1_p16"></a>

16. Туляремияның иммуноглобулиндді эритроцитарлық диагностикумы үшін ингредиенттер.

<a id="an1_p17"></a>

17. Құрғақ, туляремиялық антигенді эритроцитарлық диагностикумы.

<a id="an1_p18"></a>

18. Құрғақ, листериоздық антигенді эритроцитарлық диагностикумы.

<a id="an1_p19"></a>

19. Эритроцитарлы лептоспирозды антигенді құрғақ диагностикум.

<a id="an1_p20"></a>

20. Сібір жарасының антигенді, эритроцитарлы құрғақ диагностикумы.

<a id="an1_p21"></a>

21. Құрғақ, сібір жарасының иммуноглобулинді эритроцитарлық диагностикумы.

<a id="an1_p22"></a>

22. Құрғақ, пастереллездік антигенді эритроцитарлық диагностикум.

<a id="an1_p23"></a>

23. Құрғақ, иерсиниоздық (энтероколитик) антигенді эритроцитарлық диагностикумы.

<a id="an1_p24"></a>

24. Иерсиниоздық (Y. kristensenii) антигенді эритроцитарлық құрғақ диагностикум.

<a id="an1_p25"></a>

25. Құрғақ, псевдотуберкулездік антигенді эритроцитарлық диагностикум.

<a id="an1_p26"></a>

26. Құрғақ, бруцеллездік антигенді эритроцитарлық диагностикум.

<a id="an1_p27"></a>

27. Құрғақ, бруцеллездік иммунглобулинді эритроцитарлық диагностикум.

<a id="an1_p28"></a>

28. Сұйық, агглютинация реакциясына (АР) арналған бруцеллездік антигенді диагностикум.

<a id="an1_p29"></a>

29. Сұйық, агглютинация реакциясына (АР) арналған О-139 тырысқақтың диагностикалық үй қоянының сарысуы.

<a id="an1_p30"></a>

30. Моноспецификалық агглютинациялайтын антиабортус және антимелитензис бруцеллездік сарысу.

<a id="an1_p31"></a>

31. Эритроцитарлы сальмонеллезді поливалентті антигенді құрғақ диагностикум.

<a id="an1_p32"></a>

32. Эритроцитарлы шигеллезді поливалентті антигенді құрғақ диагностикум.

<a id="an1_p33"></a>

33. Диагностикалық оба бактериофагы Л-413 «С», құрғақ және сұйық.

<a id="an1_p34"></a>

34. Покровскаяның обаны диагностикалауға арналған сұйық және құрғақ бактериофагы.

<a id="an1_p35"></a>

35. Жалған туберкулездің диагностикалық сұйық және құрғақ бактериофагы.

<a id="an1_p36"></a>

36. Сібір жарасының құрғақ және сұйық диагностикалық «А» бактериофагы.

<a id="an1_p37"></a>

37. Тырысқақтың диагностикалық Классикалық және Эльтор, құрғақ және сұйық бактериофагтары.

<a id="an1_p38"></a>

38. Гемолизденген сұйық қан.

<a id="an1_p39"></a>

39. Бруцеллез кезінде қанды себуге арналған бактериологиялық сұйық тасымалдау жүйесі, құтыларда 2 мл-ден №5.

<a id="an1_p40"></a>

40. Нақты уақыт режимінде ПТР әдісімен сібір жарасының ДНҚ-сын анықтауға арналған «NSCEDI Anthrax qPCR» реагенттер жинағы.

<a id="an1_p41"></a>

41. Нақты уақыт режимінде ПТР әдісімен Rickettsia Spotted fever group (SFG) ДНҚ-ын анықтауға арналған «NSCEDI Rickettsia SFG qPCR» реагенттер жинағы.

<a id="an1_p42"></a>

42. Нақты уақыт режимінде ПТР әдісімен B. anthracis, Y. pestis және F. tularensis ДНҚ-сын анықтауға арналған «NSCEDI MULTI-qPCR» реагенттер жинағы.

<a id="an1_p43"></a>

43. Нақты уақыт режимінде КТ-ПТР әдісімен кене энцефалиті вирусының РНҚ-сын анықтауға арналған «NSCEDI TBE virus RT-qPCR» реагенттер жинағы.

<a id="an1_p44"></a>

44. Нақты уақыттағы полимеразалық тізбекті реакция (НУ-ПТР) әдісімен Y. pestis ДНҚ-сын анықтауға арналған «Plague qPCR» реагенттер жиынтығы.
