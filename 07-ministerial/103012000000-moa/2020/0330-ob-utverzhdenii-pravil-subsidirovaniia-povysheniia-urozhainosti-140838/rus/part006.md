## Пояснение по заполнению формы, предназначенной для сбора административных данных на безвозмездной основе «Информация об использовании субсидий по направлению «Развитие производства приоритетных культур» (индекс: форма № 1-СРПК, периодичность: годовая)

### Глава 1. Общие положения

1. Настоящее пояснение определяет единые требования по заполнению формы, предназначенной для сбора административных данных на безвозмездной основе «Информация об использовании субсидий по направлению «Развитие производства приоритетных культур» (далее – Форма).

2. Форма заполняется автоматически государственной цифровой системой субсидирования.

3. Форма подписывается руководителем, либо лицом, исполняющим его обязанности, с указанием его фамилии и инициалов.

4. Форма предоставляется местными исполнительными органами области, города республиканского значения, столицы.

5. Форма заполняется на государственном и русском языках.

## Пояснение по заполнению формы, предназначенной для сбора административных данных на безвозмездной основе «Информация об использовании субсидий по направлению «Развитие семеноводства» (индекс: форма № 3-СРС, периодичность: годовая)

### Глава 1. Общие положения

1. Настоящее пояснение определяет единые требования по заполнению формы, предназначенной для сбора административных данных на безвозмездной основе «Информация об использовании субсидий по направлению «Развитие семеноводства» (далее – Форма).

2. Форма заполняется автоматически государственной цифровой системой субсидирования.

3. Форма подписывается руководителем, либо лицом, исполняющим его обязанности, с указанием его фамилии и инициалов.

4. Форма предоставляется местными исполнительными органами области, города республиканского значения, столицы.

5. Форма заполняется на государственном и русском языках.
