# Об утверждении профессионального стандарта «Ветеринарная деятельность»

В соответствии с пунктом 5 статьи 5 Закона Республики Казахстан «О профессиональных квалификациях» ПРИКАЗЫВАЮ:

1. Утвердить прилагаемый профессиональный стандарт «Ветеринарная деятельность».

2. Управлению научного обеспечения Министерства сельского хозяйства Республики Казахстан в установленном законодательном порядке обеспечить:

   1) направление электронной копии настоящего приказа в Республиканское государственное предприятие на праве хозяйственного ведения «Институт законодательства и правовой информации Республики Казахстан» Министерства юстиции Республики Казахстан для включения в Эталонный контрольный банк нормативных правовых актов Республики Казахстан;

   2) размещение настоящего приказа на интернет ресурсе Министерства сельского хозяйства Республики Казахстан.

3. Контроль за исполнением настоящего приказа возложить на курирующего вице-министра сельского хозяйства Республики Казахстан.

4. Настоящий приказ вводится в действие со дня его первого официального опубликования.

## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`ch001`](rus/ch001.md) | Профессиональный стандарт «Ветеринарная деятельность» |
| [`ch003`](rus/ch003.md) | Глава 3. Карточки профессий |
| [`ch003-t001-r001`](rus/ch003-t001-r001.md) | `!` таблица 1, строки 1–325 |
| [`ch003-t001-r002`](rus/ch003-t001-r002.md) | таблица 1, строки 326–476 |
| [`ch004`](rus/ch004.md) | Глава 4. Технические данные профессионального стандарта |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
