# Көл-тауар және (немесе) тор қоршама шаруашылық қызметін жүзеге асыру үшін халықаралық және республикалық маңызы бар балық шаруашылығы су айдындарының және (немесе) учаскелерінің тізбесін бекіту туралы

«Аквашаруашылық туралы» Қазақстан Республикасы Заңының 9-бабы 1-тармағына сәйкес БҰЙЫРАМЫН:

<a id="p1"></a>

1. Қоса беріліп отырған көл-тауар және (немесе) тор қоршама шаруашылық қызметін жүзеге асыру үшін халықаралық және республикалық маңызы бар балық шаруашылығы су айдындарының және (немесе) учаскелерінің тізбесі бекітілсін.

<a id="p2"></a>

2. Қазақстан Республикасы Ауыл шаруашылығы министрлігінің Балық шаруашылығы комитеті заңнамада белгіленген тәртіппен:

   1) осы бұйрықтың электрондық көшірмесін Қазақстан Республикасы Нормативтік құқықтық актілерінің эталондық бақылау банкіне енгізу үшін Қазақстан Республикасы Әділет министрлігінің «Қазақстан Республикасының заңнама және құқықтық ақпарат институты» шаруашылық жүргізу құқығындағы республикалық мемлекеттік кәсіпорнына жіберілуін;

   2) осы бұйрықтың Қазақстан Республикасы Ауыл шаруашылығы министрлігінің интернет-ресурсында орналастырылуын қамтамасыз етсін.

<a id="p3"></a>

3. Осы бұйрықтың орындалуын бақылау жетекшілік ететін Қазақстан Республикасының ауыл шаруашылығы вице-министріне жүктелсін.

<a id="p4"></a>

4. Осы бұйрық алғашқы ресми жарияланған күнінен кейiн қолданысқа енгiзiледi.

**Қазақстан Республикасы Ауыл шаруашылығы министрінің міндетін атқарушы**

## Көл-тауар және (немесе) тор қоршама шаруашылық қызметін жүзеге асыру үшін халықаралық және республикалық маңызы бар балық шаруашылығы су айдындарының және (немесе) учаскелерінің тізбесі

<a id="an1_p1"></a>

1. Арал теңізі (халықаралық маңызы бар).

<a id="an1_p2"></a>

2. Каспий теңізі (халықаралық маңызы бар).

<a id="an1_p3"></a>

3. Жайық өзені (халықаралық маңызы бар).

<a id="an1_p4"></a>

4. Қиғаш өзені (халықаралық маңызы бар).

<a id="an1_p5"></a>

5. Ертіс өзені (халықаралық маңызы бар).

<a id="an1_p6"></a>

6. Жайсан көлі (халықаралық маңызы бар).

<a id="an1_p7"></a>

7. Ертіс езеніндегі Бұқтырма су қоймасы (халықаралық маңызы бар).

<a id="an1_p8"></a>

8. Ертіс өзеніндегі Өскемен су қоймасы (халықаралық маңызы бар).

<a id="an1_p9"></a>

9. Ертіс өзеніндегі Шульбинское су қоймасы (халықаралық маңызы бар).

<a id="an1_p10"></a>

10. Есіл өзені (халықаралық маңызы бар).

<a id="an1_p11"></a>

11. Тобыл өзені (халықаралық маңызы бар).

<a id="an1_p12"></a>

12. Сырдария өзені (халықаралық маңызы бар).

<a id="an1_p13"></a>

13. Сырдария өзеніндегі Шардара су қоймасы (халықаралық маңызы бар).

<a id="an1_p14"></a>

14. Іле өзені (халықаралық маңызы бар).

<a id="an1_p15"></a>

15. Іле өзеніндегі Қапшағай су қоймасы (халықаралық маңызы бар).

<a id="an1_p16"></a>

16. Нұра өзені (республикалық маңызы бар).

<a id="an1_p17"></a>

17. Сілеті өзені (республикалық маңызы бар).

<a id="an1_p18"></a>

18. Алакөл көлдер жүйесі (республикалық маңызы бар).

<a id="an1_p19"></a>

19. Балқаш көлі (республикалық маңызы бар).

<a id="an1_p20"></a>

20. Қаныш Сәтпаев атындағы канал (республикалық маңызы бар).
