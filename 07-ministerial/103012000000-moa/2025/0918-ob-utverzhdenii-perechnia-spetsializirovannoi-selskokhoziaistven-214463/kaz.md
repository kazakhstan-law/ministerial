# Ауыл шаруашылығы өнімін, аквашаруашылық (балық өсіру шаруашылығы) өнімін өндіруші заңды тұлғалар, сондай-ақ шаруа немесе фермер қожалығының басшысы және (немесе) мүшелері ауыл шаруашылығы өнімін өзі өндіру процесінде пайдаланылатын көлік құралдарына салық төлеуші болып табылмайтын мамандандырылған ауыл шаруашылығы техникасының тізбесін бекіту туралы

> *Ескерту. 01.01.2026 бастап қолданысқа енгізіледі – осы бұйрықтың 4-тармағымен.*

Қазақстан Республикасы Салық кодексінің 563-бабы 3-тармағының 1) тармақшасына сәйкес БҰЙЫРАМЫН:

<a id="p1"></a>

1. Қоса беріліп отырған ауыл шаруашылығы өнімін, аквашаруашылық (балық өсіру шаруашылығы) өнімін өндіруші заңды тұлғалар, сондай-ақ шаруа немесе фермер қожалығының басшысы және (немесе) мүшелері ауыл шаруашылығы өнімін өзі өндіру процесінде пайдаланылатын көлік құралдарына салық төлеуші болып табылмайтын мамандандырылған ауыл шаруашылығы техникасының тізбесі бекітілсін.

<a id="p2"></a>

2. Қазақстан Республикасы Ауыл шаруашылығы министрлігінің Егіншілік департаменті заңнамада белгіленген тәртіппен:

   1) осы бұйрықтың электрондық көшірмесін Қазақстан Республикасы Әділет министрлігінің «Қазақстан Республикасының Заңнама және құқықтық ақпарат институты» шаруашылық жүргізу құқығындағы республикалық мемлекеттік кәсіпорнына Қазақстан Республикасының нормативтік құқықтық актілерінің Эталондық бақылау банкiне енгізу үшін жіберілуін;

   2) осы бұйрық ресми жарияланғаннан кейін оның Қазақстан Республикасы Ауыл шаруашылығы министрлігінің интернет-ресурсында орналастырылуын қамтамасыз етсін.

<a id="p3"></a>

3. Осы бұйрықтың орындалуын бақылау жетекшілік ететін Қазақстан Республикасының ауыл шаруашылығы вице-министріне жүктелсін.

<a id="p4"></a>

4. Осы бұйрық 2026 жылғы 1 қаңтардан бастап қолданысқа енгізіледі және ресми жариялануға тиіс.

## Ауыл шаруашылығы өнімін, аквашаруашылық (балық өсіру шаруашылығы) өнімін өндіруші заңды тұлғалар, сондай-ақ шаруа немесе фермер қожалығының басшысы және (немесе) мүшелері ауыл шаруашылығы өнімін өзі өндіру процесінде пайдаланылатын көлік құралдарына салық төлеуші болып табылмайтын мамандандырылған ауыл шаруашылығы техникасының тізбесі

<a id="an1_p1"></a>

1. Сүт немесе ауыл шаруашылығы мақсаттарына су тасымалдауға арналған автомобиль-цистерналар.

<a id="an1_p2"></a>

2. Ветеринария қызметінің автомобильдері.

<a id="an1_p3"></a>

3. Автозообиологиялық зертханалар.

<a id="an1_p4"></a>

4. Автоазықтасығыштар.

<a id="an1_p5"></a>

5. Автотиеуіштер.

<a id="an1_p6"></a>

6. Дән сепкiштерге автоқұйғыштар.

<a id="an1_p7"></a>

7. Тыңайтқыш енгiзуге арналған автомашиналар.

<a id="an1_p8"></a>

8. Ұшақтарға минералды тыңайтқыштарды және улы химикаттарды автотиеуiштер.

<a id="an1_p9"></a>

9. Тең штабельдерiн автотасымалдауыштар.

<a id="an1_p10"></a>

10. Автотұзақжемшашқыш.

<a id="an1_p11"></a>

11. Пәлекжинағыш машиналар.

<a id="an1_p12"></a>

12. АН-2 ауыл шаруашылығы әуе кемесi.

<a id="an1_p13"></a>

13. Өздiгінен жүретiн дестелегiштер.

<a id="an1_p14"></a>

14. Астық жинағыш комбайндар.

<a id="an1_p15"></a>

15. Тракторлар, өздігінен жүретін шассилер және мобильді энергетикалық құралдар.

<a id="an1_p16"></a>

16. Азық жинағыш комбайндар.

<a id="an1_p17"></a>

17. Ауыл шаруашылығы машиналарын жөндеу және техникалық қызмет көрсету жөнiндегi автомобиль-шеберханалар.

<a id="an1_p18"></a>

18. Өздiгінен жүретiн шөп шапқыштар.

<a id="an1_p19"></a>

19. Маялағыштар.

<a id="an1_p20"></a>

20. Жинағыш комбайндар (тамыржемiстiлердi, картопты, қызанақты, көк бұршақты, мақтаны және басқа да ауыл шаруашылығы өнімін жинауға арналған).
