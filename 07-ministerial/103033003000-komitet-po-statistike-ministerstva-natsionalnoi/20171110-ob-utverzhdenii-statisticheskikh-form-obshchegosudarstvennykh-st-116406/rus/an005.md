## Дневник учета ежедневных расходов

```
Отчетный период          Месяц          Квартал        Часть
```

```
1. Наименование территорий (населенного пункта) ______________________________________
```

```
2. Код населенного пункта по КАТО1
3. Код типа населенного пункта (1 - город, 2 - село)
4. Код домохозяйства
5. Код лица, уполномоченного на
проведение опроса (далее – интервьюер)
Начало                   число      месяц            год
Окончание           число        месяц   	      год
```

1Классификатор административно-территориальных объектов НК РК 11-2009

Уважаемый респондент, при заполнении Дневника просим Вас руководствоваться напутствиями интервьюера и приложенной инструкцией!

```
1. Вводная часть                                                              1.1 ___________«___»___________20___года.
                                                                                                   (проставляется интервьюером)
1.2 Количество лиц,                                   1.3 Код причины не заполнения
присутствовавших в этот день                                        (проставляется интервьюером)
1.4 Скажите, был ли этот день обычным в отношении количества присутствовавших лиц?2     Да - 1
       (необычный день – проведение торжественных и ритуальных мероприятий)                      Нет - 2
```
