## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`intro`](rus/intro.md) | Об утверждении статистических форм общегосударственных статистических наблюдений по статистике строительства и инструкции по их заполнению |
| [`intro-part001`](rus/intro-part001.md) | 1. Құрылыс жұмыстарының орындалған аумағын көрсетіңіз (облыс, қала, аудан, елді мекен) |
| [`intro-part039`](rus/intro-part039.md) | Инструкция по заполнению статистической формы общегосударственного статистического наблюдения «Отчет о вводе в эксплуатацию объектов» (код 0441104, индекс 2-КС, периодичность годовая) |
| [`sec012`](rus/sec012.md) | Раздел 12 заполняется в случае ввода в эксплуатацию объектов с использованием возобновляемых источников энергии. При вводе в эксплуатацию объектов с использованием только возобновляемых источников энергии заполняется графа «Основной вид». При вводе в эксплуатацию объектов с частичным использованием возобновляемых источников энергии (кроме основного тепло и электроснабжения) заполняется графа «Вспомогательный вид». |
