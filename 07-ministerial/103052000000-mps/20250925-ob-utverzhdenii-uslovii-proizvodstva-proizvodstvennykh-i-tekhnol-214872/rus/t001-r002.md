▸ Нагрев присадок в специальных шкафах, сертифицированных по стандартам ISO 13577 и соответствующих требованиям безопасности EN 746.

– должна иметь ATEX-сертификацию (EU Directive 2014/34/EU) и соответствовать ISO 12100.
▸Технология автоматического дозирования компонентов с PPM концентрациях.
▸Технология подготовки модификатора вязкости, оснащённая высокоэффективным диспергатором, специально разработанным для смешивания присутствующих компонентов. Подача компонентов из системы VIB осуществляется по самозачистному трубопроводу с соответствующей арматурой и оборудованием.
▸Резервуары для коктейля из присадок и модификаторов вязкости должны соответствовать ГОСТ 34347-2017 или DIN EN 14015.
▸Для производства электроизоляционных масел предусмотрен этап вакуумного выпаривания влаги и газов из базового масла. Оборудование должно соответствовать стандартам ISO 10438 и DIN 28436. Контроль остаточной влаги — не более 30 ppm согласно IEC 60296
2. Блендинг (смешивание компонентов):
▸Технологический процесс работы автоматизированной смесительной установки блочного типа АВВ или SMB должен включать в себя полный цикл операций от приёма компонентов до выдачи готовой смеси, с учётом автоматизации, безопасности и контроля качества
▸Оборудование должно соответствовать стандартам: ISO 9001, ISO 13849 (машинная безопасность), ISO 14120.
▸Контроль температуры, давления и времени по ГОСТ 12.2.063-2015.
▸Технологический процесс смешения должно иметь лицензию на программное обеспечение с открытым исходным кодом (open source), обеспечивающий прозрачность и возможность независимого аудита автоматизации процессов.
▸Технологический процесс смешения должно иметь программное обеспечение с открытым исходным кодом (open source) и должно соответствовать:
- ISO/IEC 25010 – модель качества ПО (надежность, безопасность, эффективность);
- ISO/IEC 27001 – информационная безопасность;
- IEC 61508 / ISO 26262 – функциональная безопасность для автоматизированных систем.
▸Стандарты разработки исходного кода должны соответствовать:
- MISRA C / MISRA C++ - безопасный стиль программирования для встроенных систем;
- CERT – безопасные практики кодирования;
- OWASP – безопасные практики кодирования;
- ISO/IEC 12207 – процессы жизненного цикла программного обеспечения.
▸Стандарты открытого исходного кода (open-source) должны соответствовать:
- OSD (Open Source Definition by OSI);
- Контроль кода должен обеспечиваться через системы версионности (Git), сопровождаться документацией и проходить статический анализ (например, SonarQube)
3. Контроль качества
▸Испытания по ГОСТ, ISO, API, SAE.
▸Применение LIMS (лабораторной информационной системы).
▸Лабораторное оборудование должно соответствовать ISO/IEC 17025:2017
