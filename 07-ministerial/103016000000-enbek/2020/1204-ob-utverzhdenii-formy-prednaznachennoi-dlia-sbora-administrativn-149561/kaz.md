# «Ұжымдық шарттардың саны туралы мәліметтер» әкімшілік деректерді жинауға арналған нысанын бекіту туралы

«Мемлекеттік статистика туралы» 2010 жылғы 19 наурыздағы Қазақстан Республикасы Заңының 16-бабының 3-тармағының 2) тармақшасына, Қазақстан Республикасы Үкіметінің 2017 жылғы 18 ақпандағы № 81 қаулысымен бекітілген Қазақстан Республикасының Еңбек және халықты әлеуметтiк қорғау министрлігi туралы ереженің 16-тармағының 3) тармақшасына сәйкес БҰЙЫРАМЫН:

<a id="p1"></a>

1. Осы бұйрыққа қосымшаға сәйкес «Ұжымдық шарттардың саны туралы мәліметтер» әкімшілік деректерді жинауға арналған нысаны бекітілсін.

<a id="p2"></a>

2. «Әкімшілік деректерді жинауға арналған нысанды бекіту туралы» Қазақстан Республикасы Денсаулық сақтау және әлеуметтік даму министрінің 2016 жылғы 28 маусымдағы № 567 бұйрығының (Қазақстан Республикасының Әділет министрлігінде 2016 жылы 3 тамызда № 14063 болып тіркелген, «Әділет» ақпараттық-құқықтық жүйесінде 2016 жылғы 19 тамызда жарияланған) күші жойылды деп танылсын.

<a id="p3"></a>

3. Қазақстан Республикасы Еңбек және халықты әлеуметтік қорғау министрлігінің Еңбек, әлеуметтік қорғау және көші-қон комитеті заңнамада белгіленген тәртіппен:

   1) осы бұйрықты Қазақстан Республикасының Әділет министрлігінде мемлекеттік тіркеуді;

   2) осы бұйрықты Қазақстан Республикасы Еңбек және халықты әлеуметтік қорғау министрлігінің интернет-ресурсында орналастыруды;

   3) осы бұйрық Қазақстан Республикасының Әділет министрлігінде мемлекеттік тіркелгеннен кейін он жұмыс күні ішінде Қазақстан Республикасы Еңбек және халықты әлеуметтік қорғау министрлігінің Заң қызметі департаментіне осы тармақтың 1) және 2) тармақшаларында көзделген іс-шаралардың орындалуы туралы мәліметтер беруді қамтамасыз етсін.

<a id="p4"></a>

4. Осы бұйрықтың орындалуын бақылау Қазақстан Республикасының Еңбек және халықты әлеуметтік қорғау бірінші вице-министрі А.Ә. Сарбасовқа жүктелсін.

<a id="p5"></a>

5. Осы бұйрық алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

## «Ұжымдық шарттардың саны туралы мәліметтер» әкімшілік деректерді жинауға арналған нысанын толтыру жөніндегі түсіндірме

### 1-бөлім. Жалпы ережелер

<a id="an1_p1"></a>

1. Осы «Ұжымдық шарттардың саны туралы мәліметтер» әкімшілік деректерді жинауға арналған нысанын толтыру жөніндегі түсіндірме Қазақстан Республикасы Үкіметінің 2017 жылғы 18 ақпандағы № 81 қаулысымен бекітілген Қазақстан Республикасының Еңбек және халықты әлеуметтiк қорғау министрлігi туралы ереженің 16-тармағының 3) тармақшасына сәйкес әзірленіп, «Ұжымдық шарттардың саны туралы мәліметтер» әкімшілік деректерді жинауға арналған нысанын (бұдан әрі – Нысан) толтыру тәртібін нақтылайды.

<a id="an1_p2"></a>

2. Осы Нысанды жүргізудің негізгі міндеті Қазақстан Республикасы еңбек заңнамасының сақталуына мониторингті жүзеге асыру болып табылады.

<a id="an1_p3"></a>

3. Облыстардың, республикалық маңызы бар қалалардың, астананың жергілікті атқарушы органдарының еңбек инспекциясы жөніндегі басқармалары толтырылған Нысанды Қазақстан Республикасының Еңбек және және халықты әлеуметтік қорғау министрлігіне ай сайын, есепті кезеңнен кейінгі айдың 3-күніне қарай ұсынады.

<a id="an1_p4"></a>

4. Көрсеткіштер ағымдағы есепті кезеңнің бірінші күніне нақты деректер бойынша қалыптастырылады.

<a id="an1_p5"></a>

5. Нысанға бірінші басшы, ал ол болмаған жағдайда – оның міндетін атқарушы адам қол қояды.

### 2-бөлім. Нысанды толтыру жөніндегі түсіндірме

<a id="an1_p6"></a>

6. Нысанның А-бағанында өңірлердің атауы көрсетіледі.

<a id="an1_p7"></a>

7. Нысанның Б-бағанында ӘАОЖ (Әкімшілік-аумақтық объектілер жіктеуіші) бойынша орналасқан жерінің коды көрсетіледі.

<a id="an1_p8"></a>

8. Нысанның 1-бағанында жұмыс істеп тұрған кәсіпорындардың жалпы саны көрсетіледі.

<a id="an1_p9"></a>

9. Нысанның 2-бағанында жұмыс істеп тұрған мемлекеттік кәсіпорындардың жалпы саны көрсетіледі.

<a id="an1_p10"></a>

10. Нысанның 3, 4, 5-бағандарында сәйкесінше жұмыс істеп тұрған ірі, орта және кіші мемлекеттік кәсіпорындардың саны көрсетіледі.

<a id="an1_p11"></a>

11. Нысанның 6-бағанында жұмыс істеп тұрған жеке кәсіпорындардың жалпы саны көрсетіледі.

<a id="an1_p12"></a>

12. Нысанның 7, 8, 9-бағандарында сәйкесінше жұмыс істеп тұрған ірі, орта және кіші жеке кәсіпорындардың саны көрсетіледі.

<a id="an1_p13"></a>

13. Нысанның 10-бағанында ұжымдық шарттардың ағымдағы жылдың басындағы жалпы саны көрсетіледі.

<a id="an1_p14"></a>

14. Нысанның 11-бағанында ұжымдық шарттардың ағымдағы жылдың басындағы жалпы санынан қолданылу мерзімі өткен ұжымдық шарттардың саны көрсетіледі.

<a id="an1_p15"></a>

15. Нысанның 12-бағанында ұжымдық шарттардың ағымдағы жылдың басындағы жалпы санынан қолданылу мерзімі өткен ұжымдық шарттардың ішінен жаңа мерзімге қайта жасалған ұжымдық шарттардың саны көрсетіледі.

<a id="an1_p16"></a>

16. Нысанның 13-бағанында жаңадан жасалған ұжымдық шарттардың саны көрсетіледі.

<a id="an1_p17"></a>

17. Нысанның 14-бағанында қолданыстағы ұжымдық шарттардың жиыны көрсетіледі.

<a id="an1_p18"></a>

18. Нысанның 15-бағанында жұмыс істеп тұрған кәсіпорындардың жалпы санынан қолданыстағы ұжымдық шарттардың пайызы көрсетіледі.

<a id="an1_p19"></a>

19. Нысанның 16-бағанында ұжымдық шарттары бар мемлекеттік кәсіпорындардың жалпы саны көрсетіледі.

<a id="an1_p20"></a>

20. Нысанның 17-бағанында ұжымдық шарттары бар ірі мемлекеттік кәсіпорындардың жалпы саны көрсетіледі.

<a id="an1_p21"></a>

21. Нысанның 18-бағанында жұмыс істеп тұрған ірі мемлекеттік кәсіпорындардың санынан ұжымдық шарттары бар ірі мемлекеттік кәсіпорындарды қамту пайызы көрсетіледі (3-баған).

<a id="an1_p22"></a>

22. Нысанның 19-бағанында ұжымдық шарттары бар орта мемлекеттік кәсіпорындардың жалпы саны көрсетіледі.

<a id="an1_p23"></a>

23. Нысанның 20-бағанында жұмыс істеп тұрған орта мемлекеттік кәсіпорындардың санынан ұжымдық шарттары бар орта мемлекеттік кәсіпорындарды қамту пайызы көрсетіледі (4-баған).

<a id="an1_p24"></a>

24. Нысанның 21-бағанында ұжымдық шарттары бар шағын мемлекеттік кәсіпорындардың жалпы саны көрсетіледі.

<a id="an1_p25"></a>

25. Нысанның 22-бағанында жұмыс істеп тұрған шағын мемлекеттік кәсіпорындардың санынан ұжымдық шарттары бар шағын мемлекеттік кәсіпорындарды қамту пайызы көрсетіледі (5-баған).

<a id="an1_p26"></a>

26. Нысанның 23-бағанында ұжымдық шарттары бар жеке кәсіпорындардың жалпы саны көрсетіледі.

<a id="an1_p27"></a>

27. Нысанның 24-бағанында ұжымдық шарттары бар ірі жеке кәсіпорындардың жалпы саны көрсетіледі.

<a id="an1_p28"></a>

28. Нысанның 25-бағанында жұмыс істеп тұрған ірі жеке кәсіпорындардың санынан ұжымдық шарттары бар ірі жеке кәсіпорындарды қамту пайызы көрсетіледі (7-баған).

<a id="an1_p29"></a>

29. Нысанның 26-бағанында ұжымдық шарттары бар орта жеке кәсіпорындардың жалпы саны көрсетіледі.

<a id="an1_p30"></a>

30. Нысанның 27-бағанында жұмыс істеп тұрған орта жеке кәсіпорындардың санынан ұжымдық шарттары бар орта жеке кәсіпорындарды қамту пайызы көрсетіледі (8-баған).

<a id="an1_p31"></a>

31. Нысанның 28-бағанында ұжымдық шарттары бар шағын жеке кәсіпорындардың жалпы саны көрсетіледі.

<a id="an1_p32"></a>

32. Нысанның 29-бағанында жұмыс істеп тұрған шағын жеке кәсіпорындардың санынан ұжымдық шарттары бар шағын жеке кәсіпорындарды қамту пайызы көрсетіледі (9-баған).
