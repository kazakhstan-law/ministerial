# Об утверждении формы, предназначенной для сбора административных данных «Сведения о количестве коллективных договоров»

В соответствии с подпунктом 2) пункта 3 статьи 16 Закона Республики Казахстан от 19 марта 2010 года «О государственной статистике», подпунктом 3) пункта 16 Положения о Министерстве труда и социальной защиты населения Республики Казахстан, утвержденного постановлением Правительства Республики Казахстан от 18 февраля 2017 года № 81 ПРИКАЗЫВАЮ:

<a id="p1"></a>

1. Утвердить форму, предназначенную для сбора административных данных «Сведения о количестве коллективных договоров» согласно приложению к настоящему приказу.

<a id="p2"></a>

2. Признать утратившим силу приказ Министра здравоохранения и социального развития Республики Казахстан от 28 июня 2016 года № 567 «Об утверждении формы, предназначенной для сбора административных данных» (зарегистрирован в Реестре государственной регистрации нормативных правовых актов за № 14063, опубликован в информационно-правовой системе «Әділет» 19 августа 2016 года).

<a id="p3"></a>

3. Комитету труда, социальной защиты и миграции Министерства труда и социальной защиты населения Республики Казахстан в установленном законодательством порядке обеспечить:

   1) государственную регистрацию настоящего приказа в Министерстве юстиции Республики Казахстан;

   2) размещение настоящего приказа на официальном интернет-ресурсе Министерства труда и социальной защиты населения Республики Казахстан после его официального опубликования;

   3) в течение десяти календарных дней после государственной регистрации настоящего приказа в Министерстве юстиции Республики Казахстан представить в Департамент юридической службы Министерства труда и социальной защиты населения Республики Казахстан сведения об исполнении мероприятий, предусмотренных пунктом 1) и 2) настоящего приказа.

<a id="p4"></a>

4. Контроль за исполнением настоящего приказа возложить на первого вице-министра труда и социальной защиты населения Республики Казахстан Сарбасова А.А.

<a id="p5"></a>

5. Настоящий приказ вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

## Пояснение по заполнению формы, предназначенной для сбора административных данных «Сведения о количестве коллективных договоров»

### Глава 1. Общие положения

<a id="an1_p1"></a>

1. Настоящее пояснение по заполнению формы, предназначенной для сбора административных данных «Сведения о количестве коллективных договоров», разработано в соответствии с подпунктом 3) пункта 16 Положения о Министерстве труда и социальной защиты населения Республики Казахстан, утвержденного постановлением Правительства Республики Казахстан от 18 февраля 2017 года № 81, которая детализирует порядок заполнения формы, предназначенной для сбора административных данных «Сведения о количестве коллективных договоров» (далее – Форма).

<a id="an1_p2"></a>

2. Основной задачей ведения данной Формы является осуществление мониторинга за соблюдением трудового законодательства Республики Казахстан.

<a id="an1_p3"></a>

3. Заполненная Форма предоставляется в Министерство труда и социальной защиты населения Республики Казахстан местными органами по инспекции труда областей, городов республиканского значения, столицы ежемесячно к 3 числу месяца, следующего за отчетным периодом.

<a id="an1_p4"></a>

4. Показатели формируются по фактическим данным на первое число текущего отчетного периода.

<a id="an1_p5"></a>

5. Форму подписывает первый руководитель, а в случае его отсутствия – лицо, исполняющее его обязанности.

### Глава 2. Пояснение по заполнению Формы

<a id="an1_p6"></a>

6. В графе А Формы указывается наименование региона.

<a id="an1_p7"></a>

7. В графе Б Формы указывается код местонахождения по КАТО (классификатор административно-территориальных объектов).

<a id="an1_p8"></a>

8. В графе 1 Формы указывается общее количество действующих предприятий.

<a id="an1_p9"></a>

9. В графе 2 Формы указывается общее количество действующих государственных предприятий.

<a id="an1_p10"></a>

10. В графах 3, 4, 5 Формы указываются количество действующих государственных крупных, средних, малых предприятий соответственно.

<a id="an1_p11"></a>

11. В графе 6 Формы указывается общее количество действующих частных предприятий.

<a id="an1_p12"></a>

12. В графах 7, 8, 9 Формы указываются количество действующих частных крупных, средних, малых предприятий соответственно.

<a id="an1_p13"></a>

13. В графе 10 Формы указывается общее число коллективных договоров на начало текущего года.

<a id="an1_p14"></a>

14. В графе 11 Формы указывается количество коллективных договоров, по которым истекли сроки действия от общего числа коллективных договоров на начало текущего года.

<a id="an1_p15"></a>

15. В графе 12 Формы указывается количество коллективных договоров перезаключенных на новый срок из числа коллективных договоров, по которым истекли сроки действия от общего числа коллективных договоров на начало текущего года.

<a id="an1_p16"></a>

16. В графе 13 Формы указывается количество вновь заключенных коллективных договоров.

<a id="an1_p17"></a>

17. В графе 14 Формы указывается итого действующих коллективных договоров.

<a id="an1_p18"></a>

18. В графе 15 Формы указывается процент действующих коллективных договоров от общего количества действующих предприятий.

<a id="an1_p19"></a>

19. В графе 16 Формы указывается общее количество государственных предприятий, которые имеют коллективные договора.

<a id="an1_p20"></a>

20. В графе 17 Формы указывается общее количество государственных крупных предприятий, которые имеют коллективные договора.

<a id="an1_p21"></a>

21. В графе 18 Формы указывается процент охвата государственных крупных предприятий, которые имеют коллективные договора от количества действующих государственных крупных предприятий (графа 3).

<a id="an1_p22"></a>

22. В графе 19 Формы указывается общее количество государственных средних предприятий, которые имеют коллективные договора.

<a id="an1_p23"></a>

23. В графе 20 Формы указывается процент охвата государственных средних предприятий, которые имеют коллективные договора от количества действующих государственных средних предприятий (графа 4).

<a id="an1_p24"></a>

24. В графе 21 Формы указывается общее количество государственных малых предприятий, которые имеют коллективные договора.

<a id="an1_p25"></a>

25. В графе 22 Формы указывается процент охвата государственных малых предприятий, которые имеют коллективные договора от количества действующих государственных малых предприятий (графа 5).

<a id="an1_p26"></a>

26. В графе 23 Формы указывается общее количество частных предприятий, которые имеют коллективные договора.

<a id="an1_p27"></a>

27. В графе 24 Формы указывается общее количество частных крупных предприятий, которые имеют коллективные договора.

<a id="an1_p28"></a>

28. В графе 25 Формы указывается процент охвата частных крупных предприятий, которые имеют коллективные договора от количества действующих частных крупных предприятий (графа 7).

<a id="an1_p29"></a>

29. В графе 26 Формы указывается общее количество частных средних предприятий, которые имеют коллективные договора.

<a id="an1_p30"></a>

30. В графе 27 Формы указывается процент охвата частных средних предприятий, которые имеют коллективные договора от количества действующих частных средних предприятий (графа 8).

<a id="an1_p31"></a>

31. В графе 28 Формы указывается общее количество частных малых предприятий, которые имеют коллективные договора.

<a id="an1_p32"></a>

32. В графе 29 Формы указывается процент охвата частных малых предприятий, которые имеют коллективные договора от количества действующих частных малых предприятий (графа 9).
