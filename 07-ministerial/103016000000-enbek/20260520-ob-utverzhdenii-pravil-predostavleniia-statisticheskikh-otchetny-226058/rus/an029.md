## Пояснение по заполнению формы, предназначенной для сбора административных данных «Сведения по переходу получателей из одного вида выплат в другой за год»

## (Индекс: Переход-1, периодичность: ежегодно)

## 1. Общие положения

1. Настоящее Пояснение определяет единые требования по заполнению формы по сведениям по переходу получателей из одного вида выплат в другой (далее – Форма).

2. Форма заполняется и предоставляется Государственной корпорацией «Правительство для граждан» (далее – Государственная корпорация) ежегодно к 15 февраля 20__года.

3. Форму подписывает ответственное лицо Государственной корпорации, а в случае его отсутствия, лицо, выполняющее его обязанности.

## 2. Пояснение по заполнению формы

4. В графе «Всего переход (убытие)» указывается общее количество убывших получателей выплат по категориям за отчетный период.

5. В графе «Всего переход (прибытие)» указывается общее количество прибывших получателей выплат по категориям за отчетный период.

6. В графе «в том числе переход (прибытие) из выплат» указывается по категориям общее количество «государственное социальное пособие по инвалидности», «государственное социальное пособие по случаю потери кормильца», «государственное специальное пособие по списку № 1», «государственное специальное пособие по списку № 2, специальное профессиональное государственное пособие» за отчетный период.

7. В строке «Всего» указываются итоговые сведения по переходу получателей из одного вида выплат в другой за отчетный период.

1. Настоящее Пояснение определяет единые требования по заполнению формы по информации по первому разделу по следующим видам социальных выплат: пенсия и базовая пенсионная выплата; государственные социальные пособия по инвалидности, по случаю потери кормильца; государственные пособия семьям, имеющим детей – пособия по уходу за ребенком до полутора лет, пособия, воспитывающим ребенка с инвалидностью (далее – Форма).

2. Форма заполняется и предоставляется Государственной корпорацией «Правительство для граждан» (далее – Государственная корпорация) ежемесячно к 5 числу месяца, следующего за отчетным периодом.

4. В графах «Количество месяцев, за которые назначается сумма 1 раздела» указывается количество месяцев.

5. В графе «Всего получателей, человек» указывается количество получателей за отчетный период.

6. В графе «Всего сумма, тенге» указывается общая получаемая сумма в тенге за отчетный период.

7. В графе «в том числе получателей силовых структур» указывается численность и сумма выплат по получателям силовых структур за отчетный период.

8. В строке «Итого» указываются итоговые сведения по первому разделу в отчетный период.

## Пояснение по заполнению формы, предназначенной для сбора административных данных «Сведения по первому разделу в разрезе областей по видам выплат за___________(дата)»

## (Индекс: 1раздел-обл, периодичность: ежемесячно)

## 1. Общие положения

1. Настоящее Пояснение определяет единые требования по заполнению формы по первому разделу в разрезе областей по видам выплат (далее – Форма).

2. Форма заполняется и предоставляется Государственной корпорацией «Правительство для граждан» (далее – Государственная корпорация) ежемесячно к 5 числу месяца, следующего за отчетным периодом.

3. Форму подписывает ответственное лицо Государственной корпорации, а в случае его отсутствия, лицо, выполняющее его обязанности.

## 2. Пояснение по заполнению формы

4. В графе «Наименование» указывается наименование областей и городов республиканского значения.

5. В графе «Пенсионные выплаты» указывается сумма задолженности и численность по областям по базовой и солидарной пенсиям за отчетный период.

6. В графе «Государственные социальные пособия» указывается сумма задолженности и численность по областям по инвалидности, по случаю потери кормильца за отчетный период.

7. В графе «Государственные специальные пособия» указывается сумма задолженности и численность по областям по Списку № 1 и по Списку № 2 за отчетный период.

8. В графе «Государственные пособия семьям, имеющим детей» указывается сумма задолженности и численность по областям по пособиям по уходу за ребенком по достижении им возраста одного года, пособия матери или отцу, усыновителю (удочерителю), опекуну (попечителю) воспитывающему, ребенка с инвалидностью (детей с инвалидностью), пособия многодетным матерям, награжденным подвесками «Алтын алқа», «Күміс алқа» или получившим ранее звание «Мать-героиня» и награжденным орденом «Материнская слава» I и II степени, пособия многодетным семьям, имеющим 4-х и более совместно проживающих несовершеннолетних детей и пособия по уходу за лицом с инвалидностью первой группы с детства за отчетный месяц.

9. В графе «Специальное профессиональное государственное пособие» указывается сумма задолженности и численность по областям за отчетный период.

10. В строке «Итого по республике» указываются итоговые сведения по первому разделу в разрезе областей за отчетный период.

## Пояснение по заполнению формы, предназначенной для сбора административных данных «Сведения о градации участников накопительной пенсионной системы по половозрастной структуре, по доходам, с которых уплачиваются обязательные пенсионные взносы, обязательные профессиональные пенсионные взносы»

## (Индекс: ГНПС-4, периодичность: ежеквартально)

## 1. Общие положения

1. Настоящее Пояснение определяет единые требования по заполнению формы сведений о градации участников накопительной пенсионной системы по половозрастной структуре, по доходам, с которых уплачиваются обязательные пенсионные взносы, обязательные профессиональные пенсионные взносы (далее – Форма).

2. Форма заполняется и предоставляется Государственной корпорацией «Правительство для граждан» (далее – Государственная корпорация) ежеквартально к 10 числу месяца, следующего за отчетным периодом.

3. Форму подписывает ответственное лицо Государственной корпорации, а в случае его отсутствия, лицо, выполняющее его обязанности.

## 2. Пояснение по заполнению формы

4. В графе «Возраст, лет» указывается возраст от «16» - до «63 и старше» лет.

5. В графе «до 1 минимальной заработной платы (далее – МЗП)» - «от 75 МЗП и выше» указывается количество вкладчиков (женщин и мужчин), с которых уплачиваются обязательные пенсионные взносы.

6. Аналогичным образом заполняются данные по обязательным профессиональным пенсионным взносам за отчетный период.

## (Индекс: ГНПС-нр-4, периодичность: ежеквартально)

## 1. Общие положения

1. Настоящее Пояснение определяет единые требования по заполнению формы сведений о градации участников накопительной пенсионной системы из числа наемных работников по половозрастной структуре, доходам, с которых уплачиваются обязательные пенсионные взносы, обязательные профессиональные пенсионные взносы (далее – Форма).

## 2. Пояснение по заполнению формы

4. В графе «Возраст, лет» указывается возраст от «16» - до «63 и старше» лет.

5. В графе «до 1 минимальной заработной платы (далее – МЗП) – от 75 МЗП и выше» указывается общее количество вкладчиков (женщин и мужчин) из числа наемных работников, с которых уплачиваются обязательные пенсионные взносы.

## Пояснение по заполнению формы, предназначенной для сбора административных данных «Сведения о градации участников накопительной пенсионной системы из числа самостоятельно занятых лиц (в том числе только за себя и за себя, и за наемных) по половозрастной структуре, доходам, с которых уплачиваются обязательные пенсионные взносы, обязательные профессиональные пенсионные взносы»

## (Индекс: ГНПС-сл-4, периодичность: ежеквартально)

## 1. Общие положения

1. Настоящее Пояснение определяет единые требования по заполнению формы сведений о градации участников накопительной пенсионной системы из числа самостоятельно занятых лиц (в том числе только за себя и за себя, и за наемных) по половозрастной структуре, доходам, с которых уплачиваются обязательные пенсионные взносы, обязательные профессиональные пенсионные взносы (далее – Форма).

2. Форма заполняется и предоставляется Государственной корпорацией «Правительство для граждан» (далее – Государственная корпорация) ежеквартально к 10 числу месяца, следующего за отчетным периодом.

3. Форму подписывает ответственное лицо Государственной корпорации, а в случае его отсутствия, лицо, выполняющее его обязанности.

## 2. Пояснение по заполнению формы

4. В графе «Возраст, лет» указывается возраст от «16» - до «63 и старше» лет.

5. В графе «до 1 минимальной заработной платы (далее – МЗП) – от 75 МЗП и выше» указывается общее количество вкладчиков (получателей) из числа самостоятельно занятых лиц, с которых уплачиваются обязательные пенсионные взносы/обязательные профессиональные пенсионные взносы за отчетный период.

6. Аналогичным образом заполняются данные по самостоятельно занятым лицам, уплачивающим обязательные пенсионные взносы/обязательные профессиональные пенсионные взносы только за себя и за себя, и за наемных.
