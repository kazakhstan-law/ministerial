> *Приложение к форме,*  
> *предназначенной для сбора административных данных «Оперативные сведения по выплате пенсий и пособий в разрезе областей»*

## Пояснение по заполнению формы, предназначенной для сбора административных данных «Оперативные сведения по выплате пенсий и пособий в разрезе областей»

## (Индекс: 5-ОД, периодичность: ежемесячно)

### 1. Общие положения

1. Настоящее Пояснение определяет единые требования по заполнению формы по выплате пенсий и пособий в разрезе областей (далее – Форма).

2. Форма заполняется и предоставляется Государственной корпорацией «Правительство для граждан» (далее – Государственная корпорация) ежемесячно к 3 числу месяца, следующего за отчетным периодом.

3. Форму подписывает ответственное лицо Государственной корпорации, а в случае его отсутствия, лицо, выполняющее его обязанности.

### 2. Пояснение по заполнению формы

4. По строке «солидарная пенсия» указываются данные по пенсионным выплатам из Государственной корпорации;

   по строке «базовая пенсионная выплата» указываются данные по базовым пенсионным выплатам;

   по строке «выплата обязательств по государственной гарантии сохранности обязательных пенсионных взносов в едином накопительном пенсионном фонде» указываются данные по выплатам обязательств по государственной гарантии сохранности обязательных пенсионных взносов в едином накопительном пенсионном фонде;

   по строке «надбавки к пенсиям граждан, пострадавших вследствие ядерных испытаний на Семипалатинском испытательном ядерном полигоне» указываются данные по надбавкам к пенсиям граждан, пострадавших вследствие ядерных испытаний на Семипалатинском испытательном ядерном полигоне;

   по строке «Государственное социальное пособие (далее – ГСП) по инвалидности» указываются данные по государственным социальным пособиям по инвалидности;

   по строке «ГСП по случаю потери кормильца» указываются данные по государственным социальным пособиям по случаю потери кормильца;

   по строке «Государственное специальное пособие лицам, работавшим на работах с особо вредными и особо тяжкими условиями труда (Список 1)» указываются данные по государственным специальным пособиям лицам, работавшим на работах с особо вредными и особо тяжкими условиями труда (Список 1);

   по строке «Государственное специальное пособие лицам, работавшим на работах с вредными и тяжелыми условиями труда (по списку № 2)» указываются данные по государственным социальным пособиям лицам, работавшим на работах с вредными и тяжелыми условиями труда (по списку № 2);

   по строке «Лица с инвалидностью вследствие ранения, контузии, увечья или заболевания, полученных в период ВОВ (специальное государственное пособие – (далее - СГП)» указываются данные по специальным государственным пособиям лицам с инвалидностью вследствие ранения, контузии, увечья или заболевания, полученных в период ВОВ;

   по строке «Участники ВОВ (СГП)» указываются данные по специальным государственным пособиям участникам ВОВ;

   по строке «Участники Афганской войны (СГП)» указываются данные по специальным государственным пособиям участникам Афганской войны;

   по строке «Военнослужащие Республики Казахстан, выполнявшие задачи согласно межгосударственным договорам и соглашениям по усилению охраны границы Содружества Независимых Государств на Таджикско-Афганском участке (СГП)» указываются данные по специальным государственным пособиям военнослужащим Республики Казахстан, выполнявшим задачи согласно межгосударственным договорам и соглашениям по усилению охраны границы Содружества Независимых Государств на Таджикско-Афганском участке;

   по строке «Военнослужащие Республики Казахстан, принимавшие участие в качестве миротворцев в международной миротворческой операции в Ираке (СГП)» указываются данные по специальным государственным пособиям военнослужащим Республики Казахстан, принимавшим участие в качестве миротворцев в международной миротворческой операции в Ираке;

   по строке «Военнослужащие, а также лица начальствующего и рядового состава органов внутренних дел и государственной безопасности бывшего Союза ССР, принимавшие участие в урегулировании межэтнического конфликта в Нагорном Карабахе (СГП)» указываются данные по специальным государственным пособиям военнослужащим, а также лицам начальствующего и рядового состава органов внутренних дел и государственной безопасности бывшего Союза ССР, принимавшим участие в урегулировании межэтнического конфликта в Нагорном Карабахе;

   по строке «Лица, приравненные к лицам с инвалидностью вследствие ранения, контузии, увечья или заболевания, полученных в период ВОВ (СГП)» указываются данные по специальным государственным пособиям лицам, приравненным к лицам с инвалидностью вследствие ранения, контузии, увечья или заболевания, полученных в период ВОВ;

   по строке «Лица, приравненные к участникам ВОВ (СГП)» указываются данные по специальным государственным пособиям лицам, приравненным к участникам ВОВ;

   по строке «Вдовы воинов погибших (умерших, пропавших без вести) в ВОВ (СГП)» указываются данные по специальным государственным пособиям вдовам воинов погибших (умерших, пропавших без вести) в ВОВ;

   по строке «Жены (мужья) умерших лиц с инвалидностью вследствие ранения, контузии, увечья или заболевания, полученных в период ВОВ (СГП)» указываются данные по специальным государственным пособиям женам (мужьям) умерших лиц с инвалидностью вследствие ранения, контузии, увечья или заболевания, полученных в период ВОВ;

   по строке «Герои Советского Союза, кавалеры орденов Славы трех степеней (СГП)» указываются данные по специальным государственным пособиям Героям Советского Союза, кавалерам орденов Славы трех степеней;

   по строке «Лица, удостоенные звания «Қазақстанның ғарышкер-ұшқышы» указываются данные по специальным государственным пособиям лицам, удостоенным звания «Қазақстанның ғарышкер-ұшқышы»;

   по строке «Герои Социалистического труда, кавалеры орденов Трудовой Славы трех степеней (СГП)» указываются данные по специальным государственным пособиям Героям Социалистического труда, кавалерам орденов Трудовой Славы трех степеней;

   по строке «Лица, удостоенные звания «Қазақстанның Еңбек Ері» указываются данные по специальным государственным пособиям лицам, удостоенным звания «Қазақстанның Қазақстанның Еңбек Ері»;

   по строке «Лица, удостоенные звания «Халық қаһарманы» указываются данные по специальным государственным пособиям лицам, удостоенным звания «Халық қаһарманы»;

   по строке «Участники ликвидации последствий катастрофы на ЧАЭС в 1988-1989 г.г., эвакуированные из зон отчуждения и отселения в Республику Казахстан, включая детей, которые на день эвакуации находились во внутриутробном состоянии (СГП)» указываются данные по специальным государственным пособиям выплаченным участникам ликвидации последствий катастрофы на ЧАЭС эвакуированным из зон отчуждения и отселения в Республику Казахстан, включая детей, которые на день эвакуации находились во внутриутробном состоянии (СГП);

   по строке «Награжденные труженики тыла, а также лица, проработавшие (прослужившие) не менее шести месяцев в годы ВОВ (СГП)» указываются данные по специальным государственным пособиям награжденным труженикам тыла, а также лицам, проработавшим (прослужившим) не менее шести месяцев в годы ВОВ;

   по строке «Семьи погибших (умерших, пропавших без вести) военнослужащих, сотрудников органов внутренних дел и лиц, погибших при ликвидации последствий катастрофы на ЧАЭС (СГП)» указываются данные по специальным государственным пособиям семьям погибших (умерших, пропавших без вести) военнослужащих, сотрудников органов внутренних дел и лиц, погибших при ликвидации последствий катастрофы на ЧАЭС;

   по строке «Лица с инвалидностью I и II групп (СГП)» указываются данные по специальным государственным пособиям лицам с инвалидностью I и II групп;

   по строке «Лица с инвалидностью III группы (СГП)» указываются данные по специальным государственным пособиям лицам с инвалидностью III группы;

   по строке «Дети с инвалидностью до семи лет (СГП)» указываются данные по специальным государственным пособиям детям с инвалидностью до семи лет;

   по строке «Дети с инвалидностью І и ІІ группы с семи до восемнадцати лет (СГП)» указываются данные по специальным государственным пособиям детям с инвалидностью с семи до восемнадцати лет І и ІІ группы;

   по строке «Дети с инвалидностью ІІІ группы с семи до восемнадцати лет (СГП)» указываются данные по специальным государственным пособиям детям с инвалидностью с семи до восемнадцати лет ІІІ группы;

   по строке «Жертвы политических репрессий, лица, пострадавшие от политических репрессий, имеющие инвалидность или являющиеся пенсионерами (СГП)» указываются данные по специальным государственным пособиям жертвам политических репрессий, лицам, пострадавшим от политических репрессий, имеющим инвалидность или являющимся пенсионерами;

   по строке «Лица, которым назначены пенсии за особые заслуги перед Республикой Казахстан (СГП)» указываются данные по специальным государственным пособием лицам, которым назначены пенсии за особые заслуги перед Республикой Казахстан;

   по строке «Единовременная денежная компенсация пострадавшим вследствие ядерных испытаний на Семипалатинском испытательном ядерном полигоне из числа пенсионеров и получателей ГСП» указываются данные по единовременной денежной компенсации пострадавшим вследствие ядерных испытаний на Семипалатинском испытательном ядерном полигоне из числа пенсионеров и получателей ГСП;

   по строке «Единовременная денежная компенсация пострадавшим вследствие ядерных испытаний на Семипалатинском испытательном ядерном полигоне из числа работающих и неработающих граждан» указываются данные по единовременной денежной компенсации пострадавшим вследствие ядерных испытаний на Семипалатинском испытательном ядерном полигоне из числа работающих и неработающих граждан;

   по строке «Единовременная денежная компенсация реабилитированным гражданам-жертвам массовых политических репрессий» указываются данные по единовременной денежной компенсации реабилитированным гражданам-жертвам массовых политических репрессий;

   по строке «Пособие на рождение ребенка» указываются данные по пособию на рождение ребенка;

   по строке «Пособие по уходу за ребенком по достижении им возраста до полутора лет» указываются данные по пособию по уходу за ребенком до полутора лет;

   по строке «Государственное пособие матери или отцу, усыновителю (удочерителю), опекуну (попечителю), воспитывающим ребенка с инвалидностью (детей с инвалидностью)» указываются данные по пособию родителям, воспитывающим детей с инвалидностью;

   по строке «Государственное пособие лицам, осуществляющим уход за лицом с инвалидностью первой группы» указываются данные по пособию лицам, осуществляющим уход за лицом с инвалидностью первой группы;

   по строке «Пособия многодетным матерям, награжденным подвесками «Алтын алқа», «Күміс алқа» или получившим ранее звание «Мать-героиня» и награжденным орденом «Материнская слава» I-II степени» указываются данные по пособию, многодетным матерям, награжденным подвесками «Алтын алқа», «Күміс алқа» или получившим ранее звание «Мать-героиня» и награжденным орденом «Материнская слава» I-II степени;

   по строке «Пособия многодетным семьям, имеющим четырех и более совместно проживающих несовершеннолетних детей» указываются данные по по пособию многодетным семьям, имеющих четырех и более совместно проживающих несовершеннолетних детей;

   по строке «Возмещение за вред, причиненный жизни и здоровью, возложенное судом на государство в случае прекращения функционирования юридического лица» указываются данные по возмещению за вред, причиненный жизни и здоровью, возложенное судом на государство в случае прекращения функционирования юридического лица;

   по строке «Пособие на погребение пенсионеров, участников и лиц с инвалидностью вследствие ранения, контузии, увечья или заболевания, полученных в период ВОВ» указываются данные по пособию на погребение пенсионеров, участников и лиц с инвалидностью вследствие ранения, контузии, увечья или заболевания, полученных в период ВОВ;

   по строке «Пособие на погребение получателей инвалидности» указываются данные по пособию на погребение получателей инвалидности;

   по строке «Пособие на погребение получателей пособия по случаю потери кормильца» указываются данные по пособию на погребение получателей пособия по случаю потери кормильца;

   на строке «Пособие на погребение получателей пособий по возрасту» указываются данные по пособию на погребение получателей пособий по возрасту;

   на строке «Пособие на погребение получателей госспецпособия по Списку № 1, 2» указываются данные по пособию на погребение получателей госспецпособия по Списку № 1, 2;

   на строке «Субсидирование обязательных пенсионных взносов получателям социальных выплат на случай потери дохода в связи с уходом за ребенком по достижению им возраста одного года из Государственного фонда социального страхования» указываются данные по субсидированию обязательных пенсионных взносов получателям социальных выплат на случай потери дохода в связи с уходом за ребенком по достижению им возраста одного года из Государственного фонда социального страхования;

   на строке «Пособие на погребение получателей специального профессионального государственного пособия» указываются данные по пособию на погребение получателей специального профессионального государственного пособия;

5. По строкам «январь» - «декабрь» указываются данные за отчетный период по месяцам.

6. В графе «сумма» указываются выплаченные суммы за отчетный период.

7. В графе «численность» указывается численность получателей выплаченных пенсий и пособий за отчетный период.

## Пояснение по заполнению формы, предназначенной для сбора административных данных «Сведения о градации состоявшихся получателей пенсионных выплат»

## (Индекс: ГР-100, периодичность: ежемесячно)

### 1. Общие положения

1. Настоящее Пояснение определяет единые требования по заполнению формы по состоявшимся получателям пенсионных выплат (далее – Форма).

2. Форма заполняется и предоставляется Государственной корпорацией «Правительство для граждан» (далее – Государственная корпорация) ежемесячно к 5 числу месяца, следующего за отчетным периодом.

3. Форму подписывает ответственное лицо Государственной корпорации, а в случае его отсутствия, лицо, выполняющее его обязанности.

### 2. Пояснение по заполнению формы

4. В графе «№ п/п» указывается номер по порядку.

5. В графе «градация (шаг 100 тг.)» указывается размеры пенсионных выплат с диапазоном 100 тенге.

6. В графе «всего пенсионеров, человек» указывается общая численность состоявшихся получателей пенсионных выплат в каждом диапазоне размеров пенсионных выплат.

7. В графе «пенсионеры силовых структур, человек» указывается численность пенсионеров силовых структур.

8. В графе «средний размер солидарной пенсии (без БПВ), тенге» указывается средний размер солидарной пенсии без базовой пенсионной выплаты.

9. В графе «средний размер солидарной пенсии (без БПВ) без учета силовых структур, тенге» средний размер солидарной пенсии без базовой пенсионной выплаты без учета силовых структур.

10. В графе «средний размер солидарной пенсии (без БПВ) получателей силовых структур, тенге» средний размер солидарной пенсии без базовой пенсионной выплаты получателей силовых структур.

3. Форму подписывает ответственное лицо Государственной корпорации, а в случае его отсутствия, лицо, выполняющее его обязанности.

## 2. Пояснение по заполнению формы
