## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`intro`](rus/intro.md) | `!` Об утверждении правил составления налоговой отчетности |
| [`sec046`](rus/sec046.md) | 46. Раздел "Товары (работы, услуги), приобретенные на территории РК и используемые в целях облагаемого и освобожденного оборотов" заполняется при сложности определения цели использования (облагаемого или освобожденного оборота) приобретенных товаров (работ, услуг). |
| [`sec041`](rus/sec041.md) | 41. Раздел "Порча, утрата марок акцизного сбора по табачным изделиям" состоит из пяти граф: |
| [`sec017`](rus/sec017.md) | `!` 17. Раздел "Затраты, подлежащие вычету" состоит из трех граф: |
| [`sec015`](rus/sec015.md) | 15. Раздел "Объемы водопользования" заполняется в единицах измерения, указанных в строке 9: |
| [`sec014`](rus/sec014.md) | 14. Раздел "Объемы загрязнения" заполняется в единицах измерения, указанных в строке 8: |
| [`sec009`](rus/sec009.md) | `!` 9. Раздел "Сведения о лицензии" заполняется при осуществлении деятельности, подлежащей лицензированию: |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
