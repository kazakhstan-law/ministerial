# Об утверждении структуры планов гражданской обороны и планов действий по ликвидации чрезвычайных ситуаций

В соответствии с подпунктом 26) статьи 12 Закона Республики Казахстан от 11 апреля 2014 года «О гражданской защите», ПРИКАЗЫВАЮ:

<a id="p1"></a>

1. Утвердить:

   1) структуру плана гражданской обороны согласно приложению 1 к настоящему приказу;

   2) структуру плана действий по ликвидации чрезвычайных ситуаций согласно приложению 2 к настоящему приказу.

<a id="p2"></a>

2. Департаменту Гражданской обороны Министерства по чрезвычайным ситуациям Республики Казахстан обеспечить:

   1) государственную регистрацию настоящего приказа в Министерстве юстиции Республики Казахстан;

   2) официальное опубликование настоящего приказа в средствах массовой информации.

<a id="p3"></a>

3. Контроль за исполнением настоящего приказа возложить на Вице-министра по чрезвычайным ситуациям Республики Казахстан Петрова В.В.

<a id="p4"></a>

4. Настоящий приказ вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

**Министр**

**В. Божко**

## Структура плана гражданской обороны

### 1. Краткая оценка возможной обстановки в случае нападения противника

<a id="an1_p1"></a>

1. Вероятные объекты нападения при применении современных средств поражения и действий диверсионно-разведывательных групп.

<a id="an1_p2"></a>

2. Краткая характеристика объектов нападения. Особенности, влияющие на организацию и ведение гражданской обороны.

<a id="an1_p3"></a>

3. Краткая оценка возможной обстановки на объектах после нападения противника и действия диверсионных разведывательных групп. Возможные масштабы и характер последствий нападения противника.

<a id="an1_p4"></a>

4. Выводы из оценки обстановки после нападения противника.

### 2. Мероприятия при введении степеней готовности гражданcкой обороны

<a id="an1_p5"></a>

5. При введении степени готовности гражданской обороны «первоочередные мероприятия первой группы».

<a id="an1_p6"></a>

6. При введении степени готовности гражданской обороны «первоочередные мероприятия второй группы».

<a id="an1_p7"></a>

7. При введении степени готовности гражданской обороны «Общая».

### 3. Мероприятия гражданской обороны, проводимые в военное время

<a id="an1_p8"></a>

8. Оповещение органов управления гражданской защиты и населения.

<a id="an1_p9"></a>

9. Инженерная защита.

<a id="an1_p10"></a>

10. Противорадиационная, химическая и бактериологическая защита.

<a id="an1_p11"></a>

11. Медицинская защита.

<a id="an1_p12"></a>

12. Эвакуационные мероприятия.

<a id="an1_p13"></a>

13. Материально-техническое обеспечение.

<a id="an1_p14"></a>

14. Проведение аварийно-спасательных и неотложных работ.

<a id="an1_p15"></a>

15. Организация управления и связи.

<a id="an1_p16"></a>

16. Организация взаимодействия своенным командованием.

<a id="an1_p17"></a>

17. Организация и проведение мероприятий по сигналу оповещения «Внимание всем!».

    Примечание. Приложения к плану гражданской обороны:

    1) Календарный план проведения основных мероприятий начальникам гражданской обороны при переводе системы гражданской защиты на военное положение и в военное время;

    2) Возможная обстановка при применении современных средств поражения, (масштаб определяется решением соответствующих начальников гражданской обороны);

    3) Группировка сил гражданской защиты, формирования гражданской защиты (пояснительная записка);

    4) Основные мероприятия гражданской обороны по защите населения (пояснительная записка);

    5) Схема организации связи и оповещения на военное время;

    6) План эвакуации и рассредоточения(приема и размещения эвакуируемого населения) (карта, М 1:500000, пояснительная записка);

    7) План взаимодействия при выполнении мероприятий гражданской обороны с органами военного управления для областей, городов республиканского значения, столицы, района, города(пояснительная записка, карта, М 1:500000).

## Структура плана действий по ликвидации чрезвычайных ситуаций

### 1. Краткая географическая и экономическая характеристика области (города, района) и оценка возможной обстановки на ее территории при возникновении чрезвычайных ситуаций природного и техногенного характера

<a id="an2_p1"></a>

1. Рельеф, климат, растительность, гидрография.

<a id="an2_p2"></a>

2. Административно-территориальное деление и населенные пункты.

<a id="an2_p3"></a>

3. Пути сообщения и транспорт.

<a id="an2_p4"></a>

4. Оценка возможной обстановки при возникновении чрезвычайных ситуаций природного и техногенного характера.

### 2. Мероприятия, проводимые при угрозе и возникновении чрезвычайных ситуаций

<a id="an2_p5"></a>

5. Руководство мероприятиями гражданской защиты.

<a id="an2_p6"></a>

6. Оповещение органов управления гражданской защиты об угрозе и возникновении чрезвычайных ситуаций.

<a id="an2_p7"></a>

7. Мероприятия, проводимые при угрозе чрезвычайных ситуаций.

<a id="an2_p8"></a>

8. Мероприятия, проводимые при возникновении чрезвычайных ситуаций.

<a id="an2_p9"></a>

9. Организация проведения аварийно-спасательных и неотложных работ.

<a id="an2_p10"></a>

10. Эвакуационные мероприятия.

<a id="an2_p11"></a>

11. Организация взаимодействия.

<a id="an2_p12"></a>

12. Использование государственного резерва.

<a id="an2_p13"></a>

13. Организация управления и связи.

### 3. Мероприятия, проводимые по ликвидации последствий чрезвычайных ситуаций

Примечание. Приложения к плану действий по ликвидации чрезвычайных ситуаций:

1) Календарный план основных мероприятий начальника гражданской обороны при угрозе и возникновении чрезвычайных ситуаций природного и техногенного характера;

2) Расчет сил и средств гражданской защиты (пояснительная записка);

3) Расчет сил и средств гражданской защиты, привлекаемых для ликвидации последствий землетрясений в Республике Казахстан;

4) Схема организации связи и оповещения на мирное время;

5) Карта подверженности территории чрезвычайным ситуациям природного и техногенного характера.
