# Мемлекеттік өртке қарсы қызмет өрттерден қорғайтын аса маңызды мемлекеттік меншік объектілерінің тізбесін бекiту туралы

Қазақстан Республикасы Үкіметінің 2020 жылғы 23 қазандағы № 701 қаулысымен бекітілген Қазақстан Республикасы Төтенше жағдайлар министрлігі туралы ереженің 16-тармағының 67-1) тармақшасына сәйкес БҰЙЫРАМЫН:

<a id="p1"></a>

1. Мемлекеттік өртке қарсы қызмет өрттерден қорғайтын аса маңызды мемлекеттік меншік объектілерінің қоса беріліп отырған тізбесі бекітілсін.

<a id="p2"></a>

2. Қазақстан Республикасы Төтенше жағдайлар министрлігінің Өртке қарсы қызмет комитеті Қазақстан Республикасының заңнамасында белгіленген тәртіпте:

   1) осы бұйрыққа қол қойылған күннен бастап бес жұмыс күні ішінде оны ресми жариялау және Қазақстан Республикасы нормативтік құқықтық актілерінің эталондық бақылау банкіне енгізу үшін Қазақстан Республикасы Әділет министрлігінің «Қазақстан Республикасының Заңнама және құқықтық ақпарат институты» шаруашылық жүргізу құқығындағы республикалық мемлекеттік кәсіпорнына қазақ және орыс тілдерінде жіберуді;

   2) осы бұйрықты Қазақстан Республикасы Төтенше жағдайлар министрлігінің интернет-ресурсында орналастыруды қамтамасыз етсін.

<a id="p3"></a>

3. Осы бұйрықтың орындалуын бақылау жетекшілік ететін Қазақстан Республикасы Төтенше жағдайлар вице-министріне жүктелсін.

<a id="p4"></a>

4. Осы бұйрық алғаш ресми жарияланған күнінен бастап күнтізбелік он күн өткен соң қолданысқа енгізіледі.

## Мемлекеттік өртке қарсы қызметі өрттерден қорғайтын аса маңызды мемлекеттік меншік объектілерінің тізбесі

<a id="an1_p1"></a>

1. Қазақстан Республикасы Президентінің резиденциялары.

<a id="an1_p2"></a>

2. Қазақстан Республикасы Үкімет Аппаратының әкімшілік ғимараты.

<a id="an1_p3"></a>

3. Қазақстан Республикасы Парламентінің Сенат әкімшілік ғимараты.

<a id="an1_p4"></a>

4. Қазақстан Республикасы Парламентінің Мәжіліс әкімшілік ғимараты.

<a id="an1_p5"></a>

5. Қазақстан Республикасы Конституциялық Сотының әкімшілік ғимараты.

<a id="an1_p6"></a>

6. Қазақстан Республикасы Жоғарғы Сотының әкімшілік ғимараты.

<a id="an1_p7"></a>

7. Қазақстан Республикасы Бас прокуратурасының әкімшілік ғимараты.

<a id="an1_p8"></a>

8. «Министрліктер үйі» әкімшілік ғимараты.

<a id="an1_p9"></a>

9. «Қазақстан Республикасы Президентінің архиві» әкімшілік ғимараты.

<a id="an1_p10"></a>

10. Қазақстан Республикасы Президенті Іс Басқармасының автошаруашылығы.

<a id="an1_p11"></a>

11. Материалдық-техникалық қамтамасыз ету Басқармасының автошаруашылығы.
