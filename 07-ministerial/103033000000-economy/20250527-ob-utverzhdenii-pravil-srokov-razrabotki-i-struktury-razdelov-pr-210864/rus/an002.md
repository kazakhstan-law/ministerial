## Формы, предназначенные для сбора административных данных

Представляются: в уполномоченный орган по государственному планированию области, города республиканского значения, столицы

Формы, предназначенные для сбора административных данных на безвозмездной основе, размещены на интернет-ресурсе: www.gov.kz./memleket/economy

Наименование административных форм: перечень показателей, необходимых для расчета прогнозных параметров социально-экономического развития области, города республиканского значения, столицы на _____ годы по (наименование государственного органа)

Индекс форм, предназначенных для сбора административных данных на безвозмездной основе: 1-ПО

Периодичность: годовая

Отчетный период: 20__ -20___годы

Круг лиц, представляющих формы, предназначенные для сбора административных данных на безвозмездной основе: исполнительные органы области (района (города областного значения), аппарат акима города районного значения, села, поселка, сельского округа), города республиканского значения, столицы и уполномоченные органы по государственному планированию районов (города областного значения)

Срок представления форм, предназначенных для сбора административных данных на безвозмездной основе: ежегодно до 15 августа года, предшествующего планируемому периоду
