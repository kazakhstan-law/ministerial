## Правила функционирования и технические требования к внешнему шлюзу «цифрового правительства»

### Глава 1. Общие положения

1. Настоящие Правила функционирования и технические требования к внешнему шлюзу «цифрового правительства» (далее – Правила) разработаны в соответствии с частью второй пункта 6 статьи 83 Цифрового кодекса Республики Казахстан и определяют порядок функционирования и технических требований к внешнему шлюзу «цифрового правительства».

2. В настоящих Правилах используются следующие основные понятия:

   1) расширяемый язык разметки (eXtensible Markup Language) (далее – XML) – расширяемый язык разметки, используемый для хранения и передачи данных в структурированном и машиночитаемом формате;

   2) расширенный транспортный протокол (Hyper Text Transfer Protocol Secure) (далее – HTTPS) – протокол передачи данных с поддержкой шифрования в целях повышения безопасности;

   3) транспортная подпись – электронная цифровая подпись, используемая для обеспечения целостности и авторства передаваемых сообщений при информационном взаимодействии ЦС с применением спецификации безопасности веб-сервисов (Web Service Security);

   4) единая транспортная среда государственных органов (далее – ЕТС ГО) – сеть телекоммуникаций, входящая в инфраструктуру «цифрового правительства» и предназначенная для обеспечения взаимодействия локальных (за исключением локальных сетей, имеющих доступ к Интернету), ведомственных и корпоративных сетей телекоммуникаций государственных органов, их подведомственных организаций и органов местного самоуправления, а также иных субъектов цифровой среды, определенных уполномоченным органом, с соблюдением требуемого уровня кибербезопасности;

   5) цифровая система (далее – ЦС) – функционально связанный комплекс цифровых ресурсов, использующий объекты цифровой инфраструктуры с целью обеспечения создания, сбора, обработки, хранения и распространения цифровых данных, а также автоматизирующий взаимодействие субъектов цифровой среды и (или) обеспечивающий оказание услуг в цифровой среде;

   6) интеграция цифровых объектов – мероприятия по организации и обеспечению взаимодействия между цифровыми объектами посредством интеграционных сервисов с использованием стандартных протоколов передачи данных;

   7) цифровые объекты – обособленный элемент цифровой среды, созданный, используемый или передаваемый посредством цифровых технологий, обладающий уникальными цифровыми характеристиками и позволяющий субъектам цифровой среды осуществлять правомочия владения, пользования либо распоряжения в объеме, установленном законодательством Республики Казахстан;

   8) шлюз «цифрового правительства» (далее – ШЦП) – цифровой объект, предназначенный для интеграции цифровых объектов «цифрового правительства» с иными цифровыми объектами;

   9) внешний шлюз «цифрового правительства» (далее – ВШЦП) – подсистема шлюза «цифрового правительства», предназначенная для обеспечения взаимодействия цифровых объектов, находящихся в единой транспортной среде государственных органов, с цифровыми объектами, находящимися вне единой транспортной среды государственных органов;

   10) оператор «цифрового правительства» (далее – оператор) – юридическое лицо, определяемое Правительством Республики Казахстан, обеспечивающее функционирование цифровых объектов «цифрового правительства».

### Глава 2. Порядок функционирования внешнего шлюза «цифрового правительства»

3. В соответствии со статьей 98 Цифрового кодекса Республики Казахстан взаимодействие ЦС через ВШЦП обеспечивает криптографическую защиту информации.

4. Посредством ВШЦП осуществляется интеграция ШЦП с ЦС, находящихся вне ЕТС ГО. Взаимодействие ВШЦП и ЦС, находящихся вне ЕТС ГО, осуществляется по HTTPS протоколу, посредством передачи XML сообщений между сервисами. ВШЦП обеспечивает взаимодействие ЦС и не зависит от внутренней архитектуры ЦС, которые взаимодействуют через него.

5. Проверка транспортной подписи при взаимодействии с ЦС, находящихся вне ЕТС ГО, выполняется на ВШЦП. Транспортная подпись ВШЦП не содержит метку времени.

6. Системно-техническое обслуживание ВШЦП, а также управление сервисами и мониторинг ВШЦП осуществляет оператор путем обеспечения бесперебойной работы ВШЦП и непрерывности взаимодействий цифровых объектов, целостности и защиты данных, отработки ошибок при взаимодействии цифровых объектов.

7. ВШЦП работает в круглосуточном режиме, принимает сообщения от цифровых объектов на постоянной основе за исключением технологических перерывов, которые включают в себя плановые и внеплановые работы. Плановые работы на ВШЦП проводятся не более двух раз в месяц, внеплановые работы проводятся при необходимости безотлагательного обновления на ВШЦП.

### Глава 3. Технические требования к внешнему шлюзу «цифрового правительства»

8. Обмен данными между цифровыми системами соответствуют следующим техническим требованиям:

   расширенный транспортный протокол HTTPS (протокол передачи данных с поддержкой шифрования в целях повышения безопасности) c использованием уровень защищенных cокетов сертификата (Secure Sockets Layer) (далее – SSL), выданного Национальным удостоверяющим центром Республики Казахстан (далее – НУЦ РК). Данные в протоколе HTTPS передаются поверх криптографических протоколов SSL или протокол защиты транспортного уровня (Transport Layer Security) версии не ниже 1.2;

   протокол взаимодействия простой протокол доступа к объектам, основанный на XML для передачи сообщений при интеграции цифровых систем (Simple Object Access Protocol) (далее – SOAP) и передача состояния представления (Representational State Transfer (REST));

   формат передаваемых данных расширяемый язык разметки, используемый для хранения и передачи данных в структурированном и машиночитаемом формате (eXtensible Markup Language) (далее – XML) и Java Script Object Notation для веб-методов и их параметров;

   язык описания веб-сервисов и доступа к ним, основанный на языке XML (Web Services Description Language);

   язык описания структуры XML документа (XML Schema definition) для описания структур данных, подписываемых электронной цифровой подписью (далее – ЭЦП);

   структура подписанного ЭЦП XML-файла должна соответствовать спецификации Консорциума Всемирной паутины, организация, разрабатывающая и внедряющая технологические стандарты для Всемирной паутины (World Wide Web Consortium) синтаксис и обработка подписи XML («XML-Signature Syntax and Processing»);

   ЭЦП в системах с применением технологий безопасности веб-сервисов (Web Service Security) – стандарт применения функций безопасности при обмене сообщениями между веб-сервисами SOAP, выданных НУЦ РК;

   для передачи данных используется транспортный протокол (Transmission Control Protocol) один из основных протоколов передачи данных интернета, предназначенный для управления передачей данных / сетевая модель передачи данных, представленных в цифровом виде Интернет-протокол (Internet Protocol);

   взаимодействие через ВШЦП посредством виртуального частного сетевого туннеля (Virtual Private Network) для обмена информацией двух узлов.
