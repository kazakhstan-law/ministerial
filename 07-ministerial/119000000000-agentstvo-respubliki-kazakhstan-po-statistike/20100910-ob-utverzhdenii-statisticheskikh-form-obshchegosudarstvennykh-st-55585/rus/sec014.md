## Раздел 14 заполняет только самостоятельная вечерняя (сменная) общеобразовательная школа. Площадь помещений и зданий показывается в целых квадратных метрах.

В учебную площадь включаются учебные помещения для младших, средних и старших классов, помещения для трудового обучения и профессиональной ориентации, для начальной военной подготовки, кружковой работы; актовые и учебно-спортивные залы, библиотеки.

Примечание: Х – данная позиция не подлежит заполнению.

4. Арифметико-логический контроль:

1) Раздел 1. Вид организации:

   Если указали вид школы "основная средняя школа", то в статистической форме данные заполняются только по 5-9 классам. В случае, если указали вид школы "общая средняя школа", то данные должны быть заполнены хотя бы по одному из 10-12 классов.

2) Раздел 2. Признак самостоятельности организации:

   Если школа не является самостоятельной, то 7 и 13 разделы не заполняются.

3) Раздел 6. Число классов и численность учащихся по формам обучения в разбивке по классам:

   графа 1 = сумме граф 2-5 для каждой строки.

4) Раздел 7. Сведения о движении контингента:

   графа 1 = сумме граф 2-5 для каждой строки;

   строка 3 = сумме строк 4-5 для каждой графы;

   строка 6 = сумме строк 7-8 для каждой графы.

5) Раздел 9. Укажите на каком языке (языках) ведется преподавание по всем предметам в разбивке по классам:

   графа 1 = сумме граф 2-5 для каждой строки;

   строка 8 = сумме строк 1-7 для каждой графы.

6) Раздел 10. Численность учащихся в разбивке по возрастам:

   строка 1 = сумме строк 2-16 для каждой графы.

7) Раздел 11. Численность учащихся, окончивших школу или переведенных в следующий класс:

   строка 1 = сумме строк 2-9 для каждой графы.

8) Раздел 12. Численность учащихся, окончивших школу и получивших документы об окончании:

   строка 3 = сумме строк 4, 6 для каждой графы.

9) Раздел 13. Численность и состав педагогических работников:

строка 1 = сумме строк 2-3 для каждой графы;

строка 1 = строке 5 для каждой графы;

строка 5 = сумме строк 6-9 для каждой графы.
